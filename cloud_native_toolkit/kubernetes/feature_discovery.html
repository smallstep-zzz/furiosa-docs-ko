Furiosa Feature Discovery 설치#

Furiosa Feature Discovery 및 NFD#

Furiosa Feature Discovery는 FuriosaAI NPU 속성에 대한 정보를 Kubernetes 노드에 자동으로 레이블로 추가합니다 (예: NPU 종류, 개수, 다양한 버전). 이러한 레이블을 사용하여 Kubernetes 워크로드를 특정 NPU 요구 사항에 따라 스케줄링할 수 있습니다.

Furiosa Feature Discovery는 NFD(Node Feature Discovery)를 활용합니다. NFD는 하드웨어 기능을 감지하고 Kubernetes 노드를 레이블링하는 도구입니다. Furiosa Feature Discovery와 함께 사용하면 Cloud Native Toolkit이 FuriosaAI NPUs가 장착된 노드에서만 배포되도록 보장할 수 있습니다.

참고

동일 노드에 여러 버전의 장치 레벨 구성 요소(예: 펌웨어)가 존재할 경우, 관련된 레이블이 제거되어 충돌을 방지합니다.

Helm을 사용하여 Furiosa Feature Discovery 배포#

hlm 차트를 사용하면 Furiosa 기능 발견 및 NFD를 Kubernetes 클러스터에 쉽게 설치할 수 있습니다. 다음 명령은 설치 방법을 보여줍니다. Furiosa 장치 플러그인 helm 차트는 사용할 수 있습니다. furiosa-ai/helm-charts. 필요한대로 배포를 구성하려면 수정할 수 있습니다. charts/furiosa-feature-discovery/values.yaml.

helm repo add furiosa https://furiosa-ai.github.io/helm-charts
helm repo update
helm install furiosa-feature-discovery furiosa/furiosa-feature-discovery -n furiosa-system

레이블#

Furiosa Feature Discovery가 추가하는 레이블과 그 의미는 다음과 같습니다.

레이블 (Label)

값 (Value)

설명

furiosa.ai/npu.count

n

NPU 장치 수

furiosa.ai/npu.family

rngd

칩 종류

furiosa.ai/npu.product

rngd, rngd-s, rngd-max

칩 제품 이름

furiosa.ai/npu.driver.version

x.y.z

NPU 장치 드라이버 버전

furiosa.ai/npu.driver.version.major

x

NPU 장치 드라이버 버전의 주요 버전 (Major Version)

furiosa.ai/npu.driver.version.minor

y

furiosa.ai/npu.driver.version.patch

z

furiosa.ai/npu.driver.version.metadata

abcxyz

furiosa.ai/npu.driver.version.prerelease

abcxyz
