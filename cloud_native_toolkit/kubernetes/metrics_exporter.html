Furiosa 메트릭스 내보내기 설치#

Furiosa 메트릭스 내보내기#

Furiosa 메트릭 수출업자는 FuriosaAI NPU 장치와 관련된 미터의 컬렉션을 노출 프로메테우스 Kubernetes 클러스터에서, Prometheus를 사용하여 furiosa-metrics-exporter에서 제공하는 메트릭을 수집하고 Grafana 대시보드를 사용하여 시각화할 수 있습니다. 이를 쉽게 설정하려면 다음을 사용하십시오: 프로메테우스 차트 and 그라파나 furiosa-metrics-exporter Helm 차트와 함께 헬멧 차트.

Helm과 Furiosa Metrics Exporter 배포#

Furiosa 미터 수출상 helm 도표는 유효합니다 furiosa-ai/helm-charts. 필요한대로 배포를 구성하려면 수정할 수 있습니다. charts/furiosa-metrics-exporter/values.yaml. 예를 들어, Furiosa metrics Exporter Helm chart는 Prometheus annotations를 사용하여 자동적으로 메트릭 스크랩을 활성화합니다. 포트를 변경하거나 필요한 경우 Prometheus annotations를 비활성화하려면 values.yaml를 수정할 수 있습니다. 다음 명령을 실행하여 Furiosa Metrics Exporter를 배포할 수 있습니다.

helm repo add furiosa https://furiosa-ai.github.io/helm-charts
helm repo update
helm install furiosa-metrics-exporter furiosa/furiosa-metrics-exporter -n furiosa-system

대안 임명: apt를 통해 furiosa-metrics-exporter#

참고

특수 사용 케이스 또는 non-Kubernetes 환경을 위해, 당신은 대안으로 수출업자를 설치할 수 있습니다 apt 패키지

설치를 위한 최소 요구 사항 furiosa-metrics-exporter 다음 사항이 적용됩니다:

  • Ubuntu 22.04 LTS (Debian Bookworm) 이상

  • Linux 커널 6.3 또는 이후 버전

  • 시스템의 관리자 권한 (root)

  • 패키지 저장소 설정 and 사전 설치

다음으로 furiosa-metrics-exporter 패키지를 설치하십시오.

sudo apt update
sudo apt install -y furiosa-metrics-exporter

이 명령은 패키지 furiosa-libsmi 및 furiosa-metrics-exporter를 설치합니다.

구성#

Furiosa Metrics Exporter에는 다양한 command-line (CLI) 옵션이 있습니다. 다음 테이블은 CLI 옵션을 요약합니다.

Furiosa 메트릭스 내보내기 CLI 옵션#

CLI 옵션

필요성

설명

--interval <int>

Yes

초에 있는 미터 수집 간격. e.g., --interval 10 모든 10 초마다 메트릭을 수집합니다.

--port <int>

Yes

미터 HTTP 서버를 위한 항구 수. e.g., --port 6254.

--node-name <string>

No

설정하면 hostname 레이블이 메트릭에 추가됩니다. 기본값은 비어 있습니다 ("").

--kube-resources-label <bool>

No

설정된 경우 Kubernetes 리소스 라벨(이름 공간, 파드 및 컨테이너와 같은)은 메트릭스에 추가됩니다. 기본값은 false. Kubernetes에서 부유 한 메트릭스 컨텍스트를 실행할 때 권장.
