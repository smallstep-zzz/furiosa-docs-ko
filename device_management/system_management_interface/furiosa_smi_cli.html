Furiosa SMI CLI#

The furiosa-smi CLI는 다양한 서브컴맨드를 제공하고 정보를 얻기 위한 기능을 가지고 있고 장치를 통제합니다.

설치 furiosa-smi CLI#

설치하기 위해 furiosa-smi CLI furiosa-smi 패키지

설치를 위한 최소 요구 사항 furiosa-smi 다음 사항이 적용됩니다:

  • Ubuntu 22.04 LTS (Debian Bookworm) 이상

  • Linux 커널 6.3 또는 이후 버전

  • 패키지 저장소 설정 and 사전 설치

그런 다음, 다음을 설치하십시오. furiosa-smi 패키지:

sudo apt update
sudo apt install -y furiosa-smi

요약#

furiosa-smi <sub command> [option] ..

furiosa-smi info#

커널 driver를 설치한 후, 사용 가능 furiosa-smi NPU 장치가 인식되는지 확인하려면 명령을 지정합니다. 현재 이 명령은 furiosa-smi info NPU 장치의 temperature, 전력 소비 및 PCI 정보를 출력하는 명령입니다. 이 명령으로 장치를 시스템에 장착한 후에도 장치가 보이지 않으면 driver를 설치하십시오. --format full 선택 사항은 info 명령, 당신은 장치의 UUID, 일련 번호, 전원 제한 및 핵심 및 TCP 시계를 함께 볼 수 있습니다.

furiosa-smi ps#

The ps subcommand는 현재 NPU 장치를 점유하는 OS 과정에 대한 정보를 인쇄합니다.

$ furiosa-smi ps
+------+----------------------------------------------------+-------------------------------------------------------------------------------+
| PID  | NPU core                                           | CMD                                                                           |
+------+----------------------------------------------------+-------------------------------------------------------------------------------+
| 3283 | npu0:[0, 7], npu1:[0, 7], npu2:[0, 7], npu3:[0, 7] | furiosa-mlperf llama-3.1-offline ./ --devices npu:0,npu:1,npu:2,npu:3 |
+------+----------------------------------------------------+-------------------------------------------------------------------------------+

The version subcommand는 CLI와 장치 driver 버전을 표시합니다.

$ furiosa-smi version

  2026.3.0-dev

  2026.4.0, 32ffd4e

furiosa-smi topo#

The topo subcommand는 NPU 장치와 NUMA 노드의 지리학을 보여줍니다.

$ furiosa-smi topo
+--------+---------+--------+--------+--------+-----------+
| Device | npu0    | npu1   | npu2   | npu3   | NUMA node |
+--------+---------+--------+--------+--------+-----------+
| npu0   | Noc     | Bridge | Cpu    | Cpu    | 0         |
+--------+---------+--------+--------+--------+-----------+
| npu1   | Bridge  | Noc    | Cpu    | Cpu    | 0         |
+--------+---------+--------+--------+--------+-----------+
| npu2   | Cpu     | Cpu    | Noc    | Bridge | 0         |
+--------+---------+--------+--------+--------+-----------+
| npu3   | Cpu     | Cpu    | Bridge | Noc    | 0         |
+--------+---------+--------+--------+--------+-----------+

Legend:

  Noc          = Connection within the same npu chip
  Bridge       = Devices communicating via one or more PCIe switches
  Cpu          = Devices communicating exclusively within a single CPU socket
  Interconnect = Devices communicating via inter-socket links (e.g., QPI, GMI)
  Unknown      = Connection type is unidentified

furiosa-smi governor#

The governor subcommand는 장치 주지사 프로필 (근법 권한 필요)을 구성합니다.

주지사 프로필:

  • 성과: NPU 빈도를 가장 높은 쪽으로 놓으십시오

  • PowerSave : NPU 주파수를 가장 낮은 상태로 설정

$ sudo furiosa-smi governor -p powersave -i 0,1,2
npu0's governor profile is set to PowerSave
npu1's governor profile is set to PowerSave
npu2's governor profile is set to PowerSave

furiosa-smi drain#

The drain subcommand disables/enables NPU 장치 (뿌리 특권 필요).

$ sudo furiosa-smi drain set 0000:17:00.0
Successfully drained device with BDF: 0000:17:00.0

$ furiosa-smi drain list
Drained device BDF: 0000:17:00.0

$ sudo furiosa-smi drain unset 0000:17:00.0
Successfully undrained device with BDF: 0000:17:00.0

furiosa-smi power#

The power subcommand는 와트에 있는 장치 전력 한계를 형성합니다 (근법 특권을 필요로 합니다). Omitting --indices 를 참조하십시오. 이 방식은 모든 장치에 적용됩니다.

$ sudo furiosa-smi power --limit 250.5 --indices 0,1,2
npu0's power limit is set to 250.5 W
npu1's power limit is set to 250.5 W
npu2's power limit is set to 250.5 W
