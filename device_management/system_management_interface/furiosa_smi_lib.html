Furiosa SMI 라이브러리#

참고

In Furiosa SDK 2026.4.0, the Python package changed from furiosa-smi-py to furiosa-smi. Follow the migration guide to update your application.

Furiosa SMI는 FuriosaAI NPUs를 관리하고 모니터링하기 위한 프로그래밍 인터페이스를 제공하며, 여기에는 장치 검색, 드라이버 및 펌웨어 정보, 성능 지표 등이 포함됩니다.

Python API#

furiosa-smi Python 패키지를 사용하여 Python 애플리케이션에서 장치 및 상태를 쿼리합니다.

설치#

이 Python 패키지는 Python 3.10 이상을 필요로 하며, Furiosa-LLM 의 종속성으로 설치됩니다 (Furiosa-LLM 설치 참조). 별도로 Python 환경에 설치하려면:

pip install furiosa-smi

호스트에는 NPU 드라이버가 설치되어 있어야 합니다 (사전 설치 요구 사항 참조). 시스템에 설치된 명령줄 도구는 Furiosa SMI CLI를 참조하십시오.

기본 사용법#

furiosa_smi를 임포트하고, 직접 장치를 쿼리합니다. 명시적인 init() 호출은 필요하지 않습니다:

import furiosa_smi

print("Driver:", furiosa_smi.driver_info())
for device in furiosa_smi.list_devices():
    print("Device:", device.device_name())
    print("UUID:", device.uuid())
    print("Firmware:", device.firmware_version())
    print("Temperature:", device.device_temperature().ambient())
    print("Power (W):", device.power_consumption())

C API#

C API는 furiosa-libsmi 시스템 라이브러리에서 제공됩니다. (furiosa-libsmi 시스템 라이브러리)

경고

기존 furiosa-libsmi 패키지는 더 이상 사용되지 않으며, 유지 보수가 중단됩니다. 다음 지침은 기존 C API 사용자를 위한 것입니다. 현재 furiosa-smi CLI는 이 패키지를 필요로 하지 않습니다.

설치#

C API를 사용하려면 furiosa-libsmi 시스템 패키지를 설치하십시오.

라이브러리 설치를 위한 최소 요구 사항은 다음과 같습니다:

  • Ubuntu 22.04 LTS (Debian Bookworm) 또는 이후 버전

  • Linux 커널 6.3 또는 이후 버전

  • 시스템에 관리자 권한 (root)

  • 패키지 저장소 설정 및 필수 구성 요소 설치

그런 다음, 다음 단계를 사용하여 furiosa-libsmi 패키지를 설치하십시오:

sudo apt update
sudo apt install -y furiosa-libsmi

API 모듈#

이 라이브러리는 NPU 장치를 관리하고 모니터링하기 위한 다양한 기능을 제공하는 API 모듈을 제공합니다. 이러한 모듈은 개발자가 필수 하드웨어 정보, 토폴로지 세부 정보, 시스템 전체 정보 및 성능 지표에 액세스할 수 있도록 합니다.

각 모듈은 다음과 같은 기능을 제공합니다:

  • Initialize 모듈은 Furiosa SMI 라이브러리의 초기화를 처리합니다.

  • Device 모듈은 장치 사양 및 상태를 포함하여 NPU 장치 검색 및 정보를 제공합니다.

  • Topology 모듈은 장치 간 링크 유형 및 P2P 접근 가능성을 포함하여 시스템 내의 토폴로지 상태를 제공합니다.

  • System 모듈은 각 NPU 장치의 시스템 전체 정보를 제공하며, 여기에는 펌웨어 버전 및 드라이버 버전이 포함됩니다.

  • 성능 모듈은 전력 소비, 온도, 사용률 등 장치 성능 지표를 제공합니다.

이러한 모듈과 사용 가능한 함수에 대한 자세한 내용은 포괄적인 C API 문서를 참조하십시오.
