Furiosa SMI 도서관#

참고

In Furiosa SDK 2026.4.0Python 패키지가 [ ]에서 furiosa-smi-py to furiosa-smi- ⁇ 을 따라가 이주 안내서 이를 통해 애플리케이션을 업데이트할 수 있습니다.

Furiosa SMI는 장치 발견, driver 및 firmware 정보 및 성능 지표를 포함한 FuriosaAI NPU를 관리 및 모니터링하기위한 프로그래밍 인터페이스를 제공합니다.

Python API#

이 furiosa-smi Python 패키지는 Python 응용 프로그램에서 장치 및 상태를 쿼리합니다.

설치#

Python 패키지는 Python 3.10 또는 나중에 Furiosa-LLM 의존성으로 설치됩니다 (참고하십시오 Furiosa-LLM 설치). 당신의 Python 환경에 따로따로 설치하기 위하여:

pip install furiosa-smi

호스트는 NPU driver가 설치되어 있어야 합니다. 사전 설치. system-installed command-line 공구를 위해, 보십시오 Furiosa SMI CLI.

기본 사용#

수입 furiosa_smi 그리고 직접 쿼리 장치. 명시되지 않음 init() 전화가 필요합니다:

import furiosa_smi

print("Driver:", furiosa_smi.driver_info())
for device in furiosa_smi.list_devices():
    print("Device:", device.device_name())
    print("UUID:", device.uuid())
    print("Firmware:", device.firmware_version())
    print("Temperature:", device.device_temperature().ambient())
    print("Power (W):", device.power_consumption())

C API#

C API는 다음에서 제공됩니다. furiosa-libsmi 시스템 도서관

경고

유산 furiosa-libsmi 패키지는 더 이상 유지되지 않습니다. 다음 지침은 기존의 C API 사용자에게 유지됩니다. 현재 furiosa-smi CLI는 이 패키지를 필요로 하지 않습니다.

설치#

설치 furiosa-libsmi C API를 사용하는 시스템 패키지

라이브러리를 설치하기위한 최소 요구 사항은 다음과 같습니다.

  • Ubuntu 22.04 LTS (Debian Bookworm) 이상

  • Linux 커널 6.3 또는 이후 버전

  • 시스템의 관리자 권한 (root)

  • 패키지 저장소 설정 and 사전 설치

그런 다음, 다음을 설치하십시오. furiosa-libsmi 패키지:

sudo apt update
sudo apt install -y furiosa-libsmi

API 모듈#

라이브러리는 다음 API 모듈을 제공하며, 각각 NPU 장치를 관리하고 모니터링하는 데 필요한 기능을 제공합니다. 이 모듈은 개발자가 필수 하드웨어 정보, topology 세부 사항, system-wide 정보 및 성능 지표에 액세스 할 수 있도록 지원합니다.

각 단위는 뒤에 오는 특징을 제공합니다:

  • 모듈을 초기화 Furiosa SMI 라이브러리의 초기화를 처리합니다.

  • 장치 모듈 NPU Device discovery 및 정보 제공 장치 사양 and 생명력.

  • 토폴로지 모듈 시스템 내의 topology 상태를 제공합니다. device-to-device 연결 유형 and P2P 접근성.

  • 시스템 모듈 각 NPU 장치의 system-wide 정보를 제공 firmware 버전 and driver 버전.

  • 성능 모듈 장치 성능 측정을 제공합니다. 전력 소비, temperature, 사용.

이 모듈 및 사용 가능한 기능을 사용하여 자세한 내용은 포괄적 인 참조하시기 바랍니다. C API 문서.
