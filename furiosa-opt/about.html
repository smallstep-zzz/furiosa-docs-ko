공식 개발자 사이트 설명서

Programming Tensor Contraction Processors는 FuriosaAI 개발자 사이트에서 제공하는 공식 furiosa-opt 설명서입니다. 2026년 11월 22일에 공식 목차의 47개 문서를 대조했으며, 이 한국어판의 본문이 해당 설명서 전체를 포함하는 것을 확인했습니다.

각 문서 위의 원문링크는 공식 웹 문서로, 옆의 GitHub는 번역 기준 커밋의 원본 파일로 연결합니다. 저장소·런타임 안내 등 부록은 해당 GitHub 원문으로 연결합니다. 문서별 대조 결과도 공개합니다.

공식 배포본에서 비어 있는 코드 영역 세 곳은 같은 커밋의 실제 선언으로 복원했습니다. 아래의 ‘원문 상태와 참조 보정’에서 위치를 확인할 수 있습니다. 공식 사이트의 이후 변경 사항은 자동 반영되지 않습니다.

문장을 읽는 방법

  • 한국어 문단에 마우스를 올리거나 키보드로 초점을 옮기면 해당 영어 원문이 표시됩니다.
  • 모바일에서는 각 문단 왼쪽 위의 원문 버튼을 누릅니다. 바깥 영역이나 닫기 버튼으로 닫을 수 있습니다.
  • 코드의 식별자(identifier), 함수 호출, 자료형, 문자열과 수치는 원문을 유지하고 주석(comment)을 번역했습니다. 코드 블록의 원문 버튼으로 번역 전 주석도 확인할 수 있습니다.
  • 읽기 도움말 · 번역자 설명 표시는 독자의 이해를 돕기 위해 추가한 설명입니다. 영어 원문의 번역과 구분됩니다.
  • 원문의 그림·도식과 수식, 표, 관련 문서 링크를 함께 제공합니다. 원문 그림에는 영어 표기가 남아 있습니다.

용어를 읽는 기준

표기이 문서에서의 뜻
텐서(tensor)여러 축으로 위치를 정해 값을 찾는 배열
축(axis)행·열·배치처럼 데이터를 구분하는 논리 방향
매핑(mapping)논리 좌표와 물리적 배치·순서를 연결하는 규칙
슬라이스(slice)데이터 메모리와 텐서 유닛을 갖춘 병렬 처리 단위
레인(lane)수축 연산기 안에서 병렬로 곱셈·축약에 참여하는 경로
수축(contraction)두 입력을 곱한 뒤 공통 축을 따라 더해 모으는 계산
축약(reduction)한 축의 여러 값을 합·최댓값 등 하나의 값으로 모으는 연산
브로드캐스트(broadcast)같은 값을 여러 계산 위치에서 사용할 수 있게 맞춰 펼치는 동작
패킷(packet)스트림에서 한 사이클에 처리하는 값의 묶음
시퀀서(sequencer)매핑에 맞춰 값을 읽고 쓰는 순서를 만드는 장치
누산기(accumulator)여러 단계에서 나온 부분 결과를 계속 더해 보관하는 공간
스케줄(schedule)데이터 이동과 연산의 실행 시점을 정한 계획
오라클(oracle)커널 결과와 비교할 정답을 계산하는 기준 구현
내림 변환(lowering)상위 수준 표현을 하드웨어가 실행할 수 있는 더 구체적인 표현으로 바꾸는 과정
