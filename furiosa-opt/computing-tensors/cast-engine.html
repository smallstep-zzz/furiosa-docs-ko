형 변환 엔진(Cast Engine)

형 변환 엔진(Cast Engine)은 쓰기 엔진(Commit Engine)이 DM에 기록하기 전에 파이프라인의 f32/i32 결과를 bf16 같은 낮은 정밀도(lower precision)의 타입으로 줄여 저장 비용(storage cost)을 낮춥니다.

인터페이스(Interface)

CollectTensor, ContractTensor, VectorFinalTensor는 모두 같은 의미(semantics)의 .cast()를 제공합니다.

rust
//
// 형 변환 엔진(Cast Engine)은 하드웨어 제약상 `VeScalar` 입력만 받습니다. 따라서
// 이 한정(bound)은 더 넓은 트레이트(trait)가 아니라 impl에 둡니다.
impl<'l, const T: Tu, P: CanApplyCast, D: VeScalar, Chip: M, Cluster: M, Slice: M, Time: M, Packet: M, B: Backend>
    TuTensor<'l, T, P, D, Chip, Cluster, Slice, Time, Packet, B>
{
    /// 각 원소(element)를 `OutD` 타입으로 형 변환(cast)하고, 출력 패킷(output packet)을 다시 하나의
    /// 32바이트 플릿(flit) 크기로 패딩(padding)합니다.
    #[primitive(TuTensor::cast)]
    pub fn cast<OutD: Scalar, OutPacket: M>(self) -> CastTensor<'l, T, OutD, Chip, Cluster, Slice, Time, OutPacket, B>
    where
        D: CastEngineCast<OutD>,
    {
        verify_cast::<D, OutD, Packet, OutPacket>();
        CastTensor::new(self.device, self.inner.map(|v| v.cast()).transpose(false))
    }
}

.cast::<OutD, OutPacket>()는 각 원소(element)를 OutD 타입으로 변환하고, 출력이 다시 32바이트 플릿(flit) 하나가 되도록 패딩(padding)합니다. 커널 작성자는 목표 타입인 OutD와 출력 원소 배치(output element layout)인 OutPacket을 선택합니다. 나머지는 컴파일러(compiler)가 도출합니다.

형 변환 엔진(Cast Engine)은 수학적 텐서 이동(mathematical tensor move)은 아니지만, 텐서의 모양(shape)을 유지하며 원소 타입(element type)만 바꿉니다. 모든 차원(dimension)은 그대로 통과합니다. 다만 Packet 배치(layout)는 출력이 여전히 32바이트 플릿(flit) 하나에 들어가도록 다시 패딩(padding)합니다.

아래 예제는 원소(element) 8개의 i32 패킷(packet), 즉 8 × 4 = 32바이트를 i8로 형 변환(cast)합니다. 변환 후 8개 원소는 8바이트를 차지하므로, A # 32로 출력에 패딩(padding)을 더해 다시 32바이트로 맞춥니다.

rust
axes![B = 4, A = 8];

fn cast_i32_to_i8<'l, const T: Tu>(
    input: CollectTensor<'l, T, i32, m![1], m![1 # 2], m![1 # 256], m![B], m![A]>,
) -> CastTensor<'l, T, i8, m![1], m![1 # 2], m![1 # 256], m![B], m![A # 32]> {
    input.cast()
}

입력의 실제 데이터가 32바이트를 모두 채우지 않을 수도 있습니다. 아래 예제는 데이터 원소(element) 4개를 8개로 패딩(padding)한 i32 입력(A # 8, 32바이트)을, 같은 4개 원소를 32개로 패딩한 i8 출력(A # 32, 역시 32바이트)으로 변환합니다.

rust
axes![A = 4];

fn cast_padded<'l, const T: Tu>(
    input: CollectTensor<'l, T, i32, m![1], m![1 # 2], m![1 # 256], m![1], m![A # 8]>,
) -> CastTensor<'l, T, i8, m![1], m![1 # 2], m![1 # 256], m![1], m![A # 32]> {
    input.cast()
}

지원하는 형 변환(Supported Casts)

각 입력은 32바이트 플릿(flit)입니다. 지원하는 원본 타입(source type)은 f32와 i32이며, 각각 변환 가능한 목표 타입(target type)이 정해져 있습니다.

입력 타입(Input Type, D) 지원하는 출력 타입(Supported Output Types, OutD)
i32 i4, i8, i16
f32 f8e5m2, f8e4m3, bf16

성능(Performance)

형 변환 엔진(Cast Engine)은 파이프라인의 병목(bottleneck)이 되지 않습니다. 플릿(flit)에서 유효한 데이터가 차지하는 비율과 관계없이 사이클(cycle)마다 플릿 하나를 처리합니다. 후단의 쓰기 엔진(Commit Engine)은 데이터가 적게 담긴 플릿들을 모아 DM에 빈틈없이 쓰므로 DM 대역폭(bandwidth)을 낭비하지 않습니다.
