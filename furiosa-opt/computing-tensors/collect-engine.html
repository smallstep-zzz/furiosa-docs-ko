수집 엔진(Collect Engine)

후단의 모든 엔진(수축 연산기(Contraction Engine), 벡터 엔진(Vector Engine), 형 변환 엔진(Cast Engine), 전치 엔진(Transpose Engine), 쓰기 엔진(Commit Engine))은 정확히 32바이트인 *플릿(flit)*을 입력받습니다. 수집 엔진은 크기가 제각각인 패킷(packet)을 다음 두 단계를 통해 플릿 하나로 정규화(normalize)합니다.

  1. 입력 패킷(packet)을 다음 32바이트 경계까지 **패딩(pad)**합니다. 이미 32바이트 경계에 정렬되어 있다면 생략합니다.
  2. 플릿(flit) 경계에서 **분할(split)**합니다. 안쪽 32바이트는 Packet2가 되고, 바깥쪽 플릿 개수는 Time2에 흡수됩니다. 패킷이 이미 32바이트라면 생략합니다.

생성된 CollectTensor는 파이프라인(pipeline)을 따라 후단 엔진으로 이동하거나 레지스터 파일(Register Files)에 저장됩니다.

인터페이스(Interface)

SwitchTensor와 FetchTensor는 같은 의미(semantics)의 .collect()를 제공합니다. 슬라이스(slice) 간 분배가 필요 없다면 FetchTensor에서 직접 호출하여 교환 엔진(Switch Engine)을 건너뜁니다.

rust
impl<'l, const T: Tu, P: CanApplyCollect, D: Scalar, Chip: M, Cluster: M, Slice: M, Time: M, Packet: M, B: Backend>
    TuTensor<'l, T, P, D, Chip, Cluster, Slice, Time, Packet, B>
{
    /// 패킷(packet)을 정확히 32바이트, 즉 플릿(flit) 하나로 정규화(normalize)합니다.
    ///
    /// 플릿 정렬 경계(flit-aligned boundary)까지 패딩(padding)한 뒤 나눕니다. 안쪽 32바이트는
    /// `Packet2`가 되고, 바깥쪽 플릿 부분은 `Time2`에 흡수됩니다. 패킷(packet)이
    /// 이미 32바이트 이하라면 패딩(padding)만 추가합니다.
    #[primitive(TuTensor::collect)]
    pub fn collect<Time2: M, Packet2: M>(self) -> CollectTensor<'l, T, D, Chip, Cluster, Slice, Time2, Packet2, B> {
        verify_collect::<D, Time, Packet, Time2, Packet2>();
        CollectTensor::new(self.device, self.inner.transpose(false))
    }
}

예제(Examples)

플릿 하나 크기의 패킷(Single-Flit Packet)

rust
axes![A = 8, B = 32];

fn collect_identity<'l, const T: Tu>(
    input: SwitchTensor<'l, T, i8, m![1], m![1 # 2], m![1 # 256], m![A], m![B]>,
) -> CollectTensor<'l, T, i8, m![1], m![1 # 2], m![1 # 256], m![A], m![B # 32]> {
    // B=32개 원소 × 1바이트(i8) = 32바이트 = 플릿(flit) 하나.
    // Time과 Packet은 변경 없이 통과합니다.
    input.collect()
}

입력 패킷(packet)이 이미 정확히 32바이트라면 collect는 그대로 통과시킵니다. i8의 경우 B = 32개 원소 × 1바이트 = 32바이트입니다.

text
Before:   Time = m![A]
          Packet = m![B]
          ┌──────────────────────────┐
          │            B             │  32 bytes
          └──────────────────────────┘

After:    Time = m![A]
          Packet = m![B # 32]
          ┌──────────────────────────┐
          │          B # 32          │  32 bytes
          └──────────────────────────┘

플릿보다 작은 패킷(Sub-Flit Packet)

rust
axes![A = 8, B = 16];

fn collect_padding<'l, const T: Tu>(
    input: SwitchTensor<'l, T, i8, m![1], m![1 # 2], m![1 # 256], m![A], m![B]>,
) -> CollectTensor<'l, T, i8, m![1], m![1 # 2], m![1 # 256], m![A], m![B # 32]> {
    // B=16개 원소 × 1바이트 = 16바이트 < 32바이트.
    // 32바이트로 패딩(padding): Packet2 = m![B # 32].
    // 플릿(flit) 하나에 들어가므로 Time은 바뀌지 않습니다.
    input.collect()
}

입력 패킷(packet)이 32바이트보다 작으면 collect는 32바이트가 되도록 패딩(padding)합니다. i8의 경우 B = 16개 원소 × 1바이트 = 16바이트입니다.

text
Before:   Time = m![A]
          Packet = m![B]
          ┌────────────┐
          │     B      │  16 bytes
          └────────────┘

After:    Time = m![A]
          Packet = m![B # 32]
          ┌────────────┬─────────────┐
          │     B      │     pad     │  32 bytes
          └────────────┴─────────────┘

여러 플릿 크기의 패킷(Multi-Flit Packet)

rust
axes![A = 8, B = 32];

fn collect_multi_flit<'l, const T: Tu>(
    input: SwitchTensor<'l, T, bf16, m![1], m![1 # 2], m![1 # 256], m![A], m![B]>,
) -> CollectTensor<'l, T, bf16, m![1], m![1 # 2], m![1 # 256], m![A, B / 16], m![B % 16]> {
    // B=32개 원소 × 2바이트(bf16) = 64바이트 = 플릿(flit) 2개.
    // 안쪽 16개 원소 = 32바이트 → Packet2 = m![B % 16].
    // 바깥쪽 플릿(flit) 2개 → Time2 = m![A, B / 16]에 흡수합니다.
    input.collect()
}

입력 패킷(packet)이 32바이트를 넘으면 collect는 이를 플릿(flit)으로 나누고, 바깥쪽 플릿 개수를 Time에 흡수합니다. bf16의 경우 B = 32개 원소 × 2바이트 = 64바이트이므로, B / 16 = 2개의 플릿입니다.

text
Before:   Time = m![A]
          Packet = m![B]
          ┌──────────────────────────┬──────────────────────────┐
          │       B / 16 == 0        │       B / 16 == 1        │  64 bytes
          └──────────────────────────┴──────────────────────────┘
                    32 bytes                   32 bytes

After:    Time = m![A, B / 16]
          Packet = m![B % 16]
          ┌──────────────────────────┐
          │          B % 16          │  32 bytes  × B/16 time steps
          └──────────────────────────┘

패딩이 있는 여러 플릿 크기의 패킷(Multi-Flit Packet With Padding)

rust
axes![A = 8, B = 56];

fn collect_multi_flit_padded<'l, const T: Tu>(
    input: SwitchTensor<'l, T, i8, m![1], m![1 # 2], m![1 # 256], m![A], m![B]>,
) -> CollectTensor<'l, T, i8, m![1], m![1 # 2], m![1 # 256], m![A, B # 64 / 32], m![B # 64 % 32]> {
    // B가 32바이트 경계에 맞지 않으므로, 먼저 B를 32바이트의 배수로 패딩(padding)합니다.
    // B # 64=64개 원소 × 1바이트(i8) = 64바이트 = 플릿(flit) 2개.
    // 안쪽 32개 원소 = 32바이트 → Packet2 = m![B # 64 % 32].
    // 바깥쪽 플릿(flit) 2개 → Time2 = m![A, B # 64 / 32]에 흡수합니다.
    input.collect()
}

입력 패킷(packet)이 32바이트 경계에 정렬되지 않았다면 먼저 패딩(padding)합니다. i8의 B = 51개 원소 × 1바이트 = 51바이트를 64바이트로 늘리는 경우가 그 예입니다. 그런 다음 collect가 플릿(flit)으로 나누고, 바깥쪽 플릿 개수(B # 64 / 32 = 2)를 Time에 흡수합니다.

text
Before:   Time = m![A]
          Packet = m![B]
          ┌──────────────────────────┬───────────────┐
          │       B / 32 == 0        │  B / 32 == 1  │  51 bytes
          └──────────────────────────┴───────────────┘
                    32 bytes             19 bytes

Padded:   Time = m![A]
          Packet = m![B # 64]
          ┌──────────────────────────┬───────────────┬──────────┐
          │       B / 32 == 0        │  B / 32 == 1  │   pad    │  64 bytes
          └──────────────────────────┴───────────────┴──────────┘
                    32 bytes                   32 bytes

After:    Time = m![A, B # 64 / 32]
          Packet = m![B # 64 % 32]
          ┌──────────────────────────┐
          │       B # 64 % 32        │  32 bytes  × B # 64 / 32 time steps
          └──────────────────────────┘

레지스터 파일 적재(Register File Loading)

정규화(normalization)한 CollectTensor는 .to_trf()로 텐서 레지스터 파일(Tensor Register File)에, .to_vrf()로 벡터 레지스터 파일(Vector Register File)에 저장할 수 있습니다. API, 영역(region), 용량(capacity), 주소 지정 모드(address mode), 예제는 레지스터 파일(Register Files) 장에서 설명합니다.
