벡터 엔진(Vector Engine)

읽기 도움말 · 번역자 설명

벡터 엔진(Vector Engine)은 수집 엔진(Collect Engine) 또는 수축 연산기(Contraction Engine)에서 받은 값에 활성화 함수(activation function), 정규화(normalization) 등을 적용하거나 값을 축약(reduction)하는 데 쓰입니다. 수축 연산을 반드시 먼저 거칠 필요는 없습니다. 플릿(flit)은 엔진 사이에서 한 번에 전달되는 묶음입니다. 입력 값과 저장된 피연산자(operand)가 어떤 단계를 통과하는지 먼저 따라가세요.

벡터 엔진(Vector Engine)은 원소별 연산(elementwise computation)과 축약(reduction)을 수행합니다. 활성화 함수(activation)인 GELU·SiLU, 정규화(normalization)인 softmax·layer norm, 이항 연산(binary operation), 슬라이스(slice) 내부 및 슬라이스 간 축약이 대표적인 예입니다.

이 엔진은 32비트 자료형(type)인 i32와 f32만 받습니다. 앞단의 수축 연산기(Contraction Engine)를 거치면 자료형이 자동으로 확장됩니다. bf16의 곱은 f32로, i8의 곱은 i32로 누산됩니다. 수축 연산기를 건너뛰는 경로에서는 읽기 어댑터(Fetch Adapter)의 형 변환 어댑터(type-cast adapter)가 입력 자료형을 확장해야 합니다.

인터페이스(Interface)

텐서 유닛(Tensor Unit)을 한 번 호출할 때 벡터 엔진(Vector Engine)에 해당하는 구간은 vector_init()부터 vector_final()까지의 메서드 체인(method chain)입니다. 엔진은 두 부분으로 나뉩니다. 슬라이스 내부 체인(Intra-Slice Chain)은 원소별 연산·이항 연산·슬라이스별 축약 단계를 담당하고, 슬라이스 간 축약기(Inter-Slice Reducer)는 한 클러스터(cluster)의 슬라이스 256개에 걸쳐 축약합니다. vector_init()과 vector_final() 사이에서는 체인만, 축약기만, 또는 둘 다 실행할 수 있습니다. 둘 다 사용하면 실행 순서는 IntraFirst(체인 다음 축약기) 또는 InterFirst(축약기 다음 체인)입니다.

슬라이스 내부 체인(Intra-Slice Chain)은 vector_intra_slice_tag()로 진입합니다. 입력에 두 그룹을 나타내는 축(axis)이 있어 두 개의 병렬 스트림(stream)으로 나누려면 vector_intra_slice_unzip()을 사용합니다(쌍 모드(Pair Mode) 참고). 두 진입점 모두 vector_init() 바로 뒤나 슬라이스 간 축약기의 출력에서 사용할 수 있습니다. 슬라이스 간 축약기에는 vector_inter_slice_reduce()로 진입하며, vector_init() 바로 뒤 또는 전환을 지원하는 슬라이스 내부 단계에서 호출합니다. 단계별 API는 슬라이스 내부 체인과 슬라이스 간 축약기를 참고하세요.

아래 시그니처(signature)는 vector_init() 쪽의 진입 메서드만 보여 줍니다. 같은 이름의 메서드(vector_intra_slice_tag, vector_inter_slice_reduce)가 체인과 축약기의 텐서(tensor)에도 있어 두 부분 사이를 전환할 수 있습니다. 이 전환은 각 하위 문서에서 설명합니다.

rust
impl<'l, const T: Tu, P: CanApplyVectorInit, D: VeScalar, Chip: M, Cluster: M, Slice: M, Time: M, Packet: M>
    TuTensor<'l, T, P, D, Chip, Cluster, Slice, Time, Packet>
{
    /// 이 텐서(tensor)에 대한 벡터 엔진(Vector Engine) 처리를 초기화합니다.
    #[primitive(TuTensor::vector_init)]
    pub fn vector_init(self) -> VectorInitTensor<'l, T, D, Chip, Cluster, Slice, Time, Packet> {
        VectorInitTensor::new(self.device, self.inner)
    }
}

impl<'l, const T: Tu, D: VeScalar, Chip: M, Cluster: M, Slice: M, Time: M, Packet: M>
    VectorInitTensor<'l, T, D, Chip, Cluster, Slice, Time, Packet>
{
    /// 벡터 엔진(VE)의 슬라이스 내부 파이프라인(intra-slice pipeline)에 단일 스트림(single stream)으로 진입합니다.
    #[primitive(VectorInitTensor::vector_intra_slice_tag)]
    pub fn vector_intra_slice_tag(
        self,
        branch: TagMode<D>,
    ) -> VectorBranchTensor<'l, T, D, Chip, Cluster, Slice, Time, Packet, Fresh, { VeOrder::IntraFirst }> {
        VectorBranchTensor::new(self.device, self.inner, branch)
    }

    /// 벡터 엔진(VE)의 슬라이스 내부 파이프라인(intra-slice pipeline)에 두 그룹(two-group / unzip)으로 진입합니다.
    #[primitive(VectorInitTensor::vector_intra_slice_unzip)]
    pub fn vector_intra_slice_unzip<I: AxisName, SplitTime: M>(
        self,
    ) -> VectorTensorPair<'l, T, D, stage::Tag, Chip, Cluster, Slice, SplitTime, Packet> {
        verify_vector_intra_slice_unzip::<I, Time, SplitTime, Packet>();
        VectorTensorPair::new::<I, Time>(self.device, self.inner)
    }
}

impl<'l, const T: Tu, Chip: M, Cluster: M, Slice: M, Time: M, Packet: M>
    VectorInitTensor<'l, T, i32, Chip, Cluster, Slice, Time, Packet>
{
    /// 벡터 엔진(VE)의 첫 연산으로 i32의 슬라이스 간 축약(inter-slice reduce)을 수행합니다.
    #[primitive(VectorInitTensor::vector_inter_slice_reduce)]
    pub fn vector_inter_slice_reduce<OutSlice: M, OutTime: M>(
        self,
        op: InterSliceReduceOpI32,
    ) -> VectorInterSliceReduceTensor<'l, T, i32, Chip, Cluster, OutSlice, OutTime, Packet, { VeOrder::InterFirst }>
    {
        let reduced = self.inner.reduce(op.reduce_fn(), op.identity(), true);
        create_inter_slice_reduce_tensor(self.device, reduced)
    }
}

예제(Examples)

벡터 엔진(Vector Engine)의 호출 형태를 파악할 수 있도록 대표적인 예제를 먼저 살펴봅니다. 전체 API 설명은 하위 문서인 슬라이스 내부 체인(Intra-Slice Chain)과 슬라이스 간 축약기(Inter-Slice Reducer)에서 다룹니다.

ReLU 활성화 함수(ReLU Activation)

이 처리 단계(pass)는 각 원소에 ReLU를 적용하여 output[b, k, m, n] = \max(input[b, k, m, n], 0)을 계산합니다.

rust
axes![B = 2, K = 256, M = 16, N = 16];

// 배치 행렬곱(batched matrix multiplication) 뒤에 ReLU 활성화 함수를 적용합니다.
// 체인만 사용하는 처리이므로 축약기는 건너뛰며, 경로는 자연스럽게 IntraFirst로 결정됩니다.
// 두 클러스터(B = 2)와 슬라이스 256개(K) 모두 실제 데이터를 담으며 패딩(padding)은 없습니다.
fn relu<'l, const T: Tu>(
    input: ContractTensor<'l, T, f32, m![1], m![B], m![K], m![M, N / 8], m![N % 8]>,
) -> VectorFinalTensor<'l, T, f32, m![1], m![B], m![K], m![M, N / 8], m![N % 8]> {
    input
        .vector_init()
        .vector_intra_slice_tag(TagMode::Zero)
        // max(x, 0): ReLU 연산 자체입니다.
        .vector_clip(ClipBinaryOpF32::Max, 0.0f32)
        .vector_final()
}

ReLU 적용 후 축약(Reduce)

이 처리 단계(pass)는 각 슬라이스(slice)에 ReLU를 적용한 뒤 R에 걸쳐 축약하여 output[a, b] = \sum_{r \in R} \max(input[a, b, r], 0)을 계산합니다.

rust
axes![A = 512, B = 2, R = 4];

// 체인에서 ReLU를 적용한 다음, 축약기가 여러 슬라이스(slice)의 값을 합산합니다.
// IntraFirst 형태: 체인을 먼저 실행하고 그다음 축약기를 실행합니다.
// 두 클러스터(B = 2), 슬라이스 256개(A / 8 * R), Way8 패킷 전체(A % 8)에 실제 데이터가 있습니다.
fn relu_then_reduce<'l, const T: Tu>(
    input: CollectTensor<'l, T, i32, m![1], m![B], m![A / 8, R], m![1], m![A % 8]>,
) -> VectorFinalTensor<'l, T, i32, m![1], m![B], m![A / 8, 1 # 4], m![1], m![A % 8]> {
    input
        .vector_init()
        .vector_intra_slice_tag(TagMode::Zero)
        // max(x, 0): ReLU 연산입니다.
        .vector_clip(ClipBinaryOpI32::Max, 0)
        // R에 해당하는 슬라이스(slice)들을 합산합니다.
        .vector_inter_slice_reduce::<m![A / 8, 1 # 4], m![1]>(InterSliceReduceOpI32::AddSat)
        .vector_final()
}

축약(Reduce) 후 편향(Bias) 더하기

이 처리 단계(pass)는 R에 걸쳐 축약한 뒤 상수 편향(bias)을 더하여 output[a, b] = \left(\sum_{r \in R} input[a, b, r]\right) + 100을 계산합니다.

rust
axes![A = 512, B = 2, R = 4];

// 축약기가 여러 슬라이스(slice)를 합산한 뒤, 체인이 축약 결과에 편향(bias)을 더합니다.
// InterFirst 형태: 축약기를 먼저 실행하고 그다음 체인을 실행합니다.
// 두 클러스터(B = 2), 슬라이스 256개, Way8 패킷 전체에 실제 데이터가 있습니다.
fn reduce_then_add<'l, const T: Tu>(
    input: CollectTensor<'l, T, i32, m![1], m![B], m![A / 8, R], m![1], m![A % 8]>,
) -> VectorFinalTensor<'l, T, i32, m![1], m![B], m![A / 8, 1 # 4], m![1], m![A % 8]> {
    input
        .vector_init()
        // R에 해당하는 슬라이스(slice)들을 합산합니다.
        .vector_inter_slice_reduce::<m![A / 8, 1 # 4], m![1]>(InterSliceReduceOpI32::AddSat)
        .vector_intra_slice_tag(TagMode::Zero)
        // 편향(bias) 100을 더합니다.
        .vector_fxp(FxpBinaryOp::AddFxp, 100)
        .vector_final()
}

슬라이스 내부 및 슬라이스 간 축약(Intra- and Inter-Slice Reduction)

이 처리 단계(pass)는 슬라이스 내부 축약기(intra-slice reducer)로 R의 Time·Packet 부분을 축약하고, 슬라이스 간 축약기(inter-slice reducer)로 R의 Slice 부분을 축약하여 R 전체를 제거합니다. einsum 표기법으로는 BR -> B이며, 포화 덧셈(saturating addition)을 사용합니다.

rust
axes![B = 2, R = 8192];

// R을 Slice(R / 32 = 256), Time(R % 32 / 4 = 8), Packet(R % 4, Way8에서 8까지 패딩)에 나누어 배치합니다.
// 체인이 R의 Time·Packet 부분을 슬라이스 내부에서 축약하고, 이어서 축약기가 Slice 부분을 축약합니다.
// IntraFirst 형태: 체인을 먼저 실행하고 그다음 축약기를 실행합니다.
fn full_sum<'l, const T: Tu>(
    input: CollectTensor<'l, T, i32, m![1], m![B], m![R / 32], m![R % 32 / 4], m![R % 4 # 8]>,
) -> VectorFinalTensor<'l, T, i32, m![1], m![B], m![1 # 256], m![1], m![1 # 8]> {
    input
        .vector_init()
        .vector_intra_slice_tag(TagMode::Zero)
        // Way8 → Way4: 패킷 뒤쪽의 4개 위치는 패딩(padding)이었습니다.
        .vector_narrow_trim::<m![R % 4]>()
        // R의 Time·Packet 부분을 합산합니다.
        .vector_intra_slice_reduce::<R, m![1], m![1 # 4]>(IntraSliceReduceOpI32::AddSat)
        // Way4 → Way8
        .vector_widen_pad::<m![1 # 8]>()
        // 슬라이스(slice) 256개 전체에 걸쳐 R의 Slice 부분을 합산합니다.
        .vector_inter_slice_reduce::<m![1 # 256], m![1]>(InterSliceReduceOpI32::AddSat)
        .vector_final()
}

쌍 덧셈(Pair Add)

이 처리 단계(pass)는 I를 따라 교차 배치된(interleaved) 두 그룹을 분리한 뒤 대응하는 값끼리 더합니다. einsum 표기법으로는 ABI -> AB입니다.

rust
axes![A = 2048, B = 2, I = 2];

// unzip으로 쌍 모드(pair mode)에 진입한 뒤, zip 연산이 두 스트림(stream)을 덧셈으로 결합합니다.
// 두 클러스터(B = 2), 슬라이스 256개(A / 8), Way8 패킷 전체(A % 8)에 실제 데이터가 있습니다.
fn pair_add<'l, const T: Tu>(
    input: CollectTensor<'l, T, i32, m![1], m![B], m![A / 8], m![I], m![A % 8]>,
) -> VectorFinalTensor<'l, T, i32, m![1], m![B], m![A / 8], m![1], m![A % 8]> {
    input
        .vector_init()
        // I를 따라 그룹 0과 그룹 1로 분리합니다.
        .vector_intra_slice_unzip::<I, m![1]>()
        // group0 + group1
        .vector_clip_zip(ClipBinaryOpI32::AddFxp)
        .vector_final()
}
