슬라이스 간 축약기(Inter-Slice Reducer)

슬라이스 간 축약기(Inter-Slice Reducer)는 한 클러스터(cluster)의 슬라이스(slice) 256개에 걸쳐 텐서(tensor)를 축약합니다. Chip·Cluster·Packet은 유지하고 Slice·Time을 OutSlice·OutTime으로 바꿉니다. 입력 모드에 관계없이 출력 텐서는 항상 Way8입니다.

인터페이스(Interface)

축약기(reducer)는 vector_init() 바로 뒤에서 진입할 수도 있고(아래에 제시한 InterFirst 경로), 전환을 지원하는 슬라이스 내부 단계에서 진입할 수도 있습니다(IntraFirst 경로에서는 슬라이스 내부 텐서에 같은 vector_inter_slice_reduce() 메서드를 호출합니다). 아래 시그니처(signature)는 VectorInitTensor 버전입니다. 전환을 지원하는 단계의 슬라이스 내부 텐서에도 같은 메서드가 있으므로 호출 형태는 동일합니다.

슬라이스 간 축약기(Inter-Slice Reducer)는 i32와 f32용 API를 각각 제공합니다.

i32 연산(Operations)

rust
impl<'l, const T: Tu, Chip: M, Cluster: M, Slice: M, Time: M, Packet: M>
    VectorInitTensor<'l, T, i32, Chip, Cluster, Slice, Time, Packet>
{
    /// 벡터 엔진(VE)의 첫 연산으로 i32의 슬라이스 간 축약(inter-slice reduce)을 수행합니다.
    #[primitive(VectorInitTensor::vector_inter_slice_reduce)]
    pub fn vector_inter_slice_reduce<OutSlice: M, OutTime: M>(
        self,
        op: InterSliceReduceOpI32,
    ) -> VectorInterSliceReduceTensor<'l, T, i32, Chip, Cluster, OutSlice, OutTime, Packet, { VeOrder::InterFirst }>
    {
        let reduced = self.inner.reduce(op.reduce_fn(), op.identity(), true);
        create_inter_slice_reduce_tensor(self.device, reduced)
    }
}

InterSliceReduceOpI32 연산(operation):

연산(Operation) 설명(Description)
Add 오버플로 시 순환하는 덧셈(wrapping addition)
AddSat 포화 덧셈(saturating addition)
Max 최댓값(maximum)
Min 최솟값(minimum)

f32 연산(Operations)

impl<'l, const T: Tu, Chip: M, Cluster: M, Slice: M, Time: M, Packet: M>
    VectorInitTensor<'l, T, f32, Chip, Cluster, Slice, Time, Packet>
{
    /// 벡터 엔진(VE)의 첫 연산으로 f32의 슬라이스 간 축약(inter-slice reduce)을 수행합니다.
    #[primitive(VectorInitTensor::vector_inter_slice_reduce)]
    pub fn vector_inter_slice_reduce<OutSlice: M, OutTime: M>(
        self,
        op: InterSliceReduceOpF32,
    ) -> VectorInterSliceReduceTensor<'l, T, f32, Chip, Cluster, OutSlice, OutTime, Packet, { VeOrder::InterFirst }>
    {
        let reduced = self.inner.reduce(op.reduce_fn(), op.identity(), true);
        create_inter_slice_reduce_tensor(self.device, reduced)
    }
}

InterSliceReduceOpF32 연산(operation):

연산(Operation) 설명(Description)
Add 부동소수점 덧셈(floating-point addition)
Max 최댓값(maximum)
Min 최솟값(minimum)
Mul 부동소수점 곱셈(floating-point multiplication)

제약 조건(Constraints)

지원되는 Slice → OutSlice 및 Time → OutTime 형태(shape)는 다음 네 가지 규칙을 따릅니다.

  1. 가장 안쪽부터 축약합니다(reduce from innermost). Slice에서 축약할 부분은 가장 안쪽 인자(factor)들이어야 합니다. 또한 연속적으로 배치되어야 하며 축약 비율(reduction ratio) r에 해당하는 구간에서 스트라이드(stride)가 1이어야 합니다.
  2. 축약된 축의 자리를 대체합니다(replacement on the reduced axis). 축약된 각 인자(factor)가 차지하던 OutSlice의 슬롯(slot)은 더미(dummy, 1 # n), 새로운 차원에 대한 브로드캐스트(broadcast), Time에서 승격한(promotion) 차원 중 하나로 채웁니다.
  3. 대체 방식을 자유롭게 섞을 수 있습니다. 더미(dummy), 브로드캐스트(broadcast), 승격(promotion) 슬롯은 OutSlice 안에서 어떤 순서로든 함께 배치할 수 있습니다.
  4. Time에서 OutSlice로 승격하면 순서가 바뀔 수 있습니다. Time → OutTime 부분에서는 남아 있는 인자(factor)의 상대 순서가 유지됩니다. 반면 Time → OutSlice 승격(promotion) 경로는 순서를 유지하지 않습니다. 승격된 인자가 OutSlice에서 차지하는 위치는 원래 Time에서의 위치와 독립적입니다.

예제(Examples)

아래 예제의 수식은 einsum 표기법을 사용합니다. 입력 쪽에만 있고 출력 쪽에는 없는 차원(dimension)은 축약되어 합산되며, 출력 쪽에만 있고 입력 쪽에는 없는 차원은 브로드캐스트(broadcast)됩니다.

더미로 대체하기(Dummy Replacement)

이 처리 단계(pass)는 R에 걸쳐 입력을 합산하고 결과를 더미 슬롯(dummy slot)에 놓습니다. einsum 표기법으로는 AR -> A입니다.

rust
axes![A = 512, B = 2, R = 4];

// R을 축약한 자리를 다른 차원이 채우지 않으면, 출력은 그 자리를 1 # n 더미(dummy)로 유지합니다.
// 한 위치에 축약 결과가 들어가고, 나머지 n - 1개 위치는 패딩(padding)입니다.
// `# n`은 차원의 다중도(multiplicity)를 나타냅니다(매핑 표현식 문서 참고).
fn inter_slice_add<'l, const T: Tu>(
    input: CollectTensor<'l, T, i32, m![1], m![B], m![A / 8, R], m![1], m![A % 8]>,
) -> VectorFinalTensor<'l, T, i32, m![1], m![B], m![A / 8, 1 # 4], m![1], m![A % 8]> {
    input
        .vector_init()
        // R을 합산합니다. 비워진 R 슬롯은 OutSlice에서 1 # 4 더미(dummy)가 됩니다.
        .vector_inter_slice_reduce::<m![A / 8, 1 # 4], m![1]>(InterSliceReduceOpI32::AddSat)
        .vector_final()
}
text
Slice = [A / 8, R]  ->  [A / 8, 1 # 4]
Time  = [1]         ->  [1]

새로운 슬라이스 차원으로 브로드캐스트하기(Broadcast)

이 처리 단계(pass)는 R을 축약하고 결과를 새로운 차원(dimension) X에 걸쳐 브로드캐스트(broadcast)합니다. einsum 표기법은 PRW -> PWX이며, 출력 쪽에 새로 등장하는 X가 브로드캐스트를 나타냅니다.

rust
axes![B = 2, P = 8, R = 4, W = 64, X = 4];

// 축약 대상이 아닌 새로운 차원 X가 R이 비운 자리를 차지합니다.
// 축약 결과를 X의 모든 위치에 브로드캐스트(broadcast)합니다.
fn broadcast_into_x<'l, const T: Tu>(
    input: CollectTensor<'l, T, f32, m![1], m![B], m![W, R], m![1], m![P]>,
) -> VectorFinalTensor<'l, T, f32, m![1], m![B], m![W, X], m![1], m![P]> {
    input
        .vector_init()
        // R을 합산한 결과를 X(새로운 OutSlice 차원)에 걸쳐 브로드캐스트(broadcast)합니다.
        .vector_inter_slice_reduce::<m![W, X], m![1]>(InterSliceReduceOpF32::Add)
        .vector_final()
}
text
Slice = [W, R]  ->  [W, X]
Time  = [1]     ->  [1]

Time에서 OutSlice로 승격하기(Promotion)

이 처리 단계(pass)는 R을 축약하고 Time의 차원(dimension) V를 OutSlice로 승격(promotion)합니다. einsum 표기법으로는 PRSUVW -> PSUVW입니다.

rust
axes![B = 2, P = 8, R = 4, S = 2, U = 2, V = 4, W = 64];

// Time의 차원(여기서는 V)을 OutSlice로 승격(promotion)하여 R의 자리를 채웁니다.
// 승격할 차원이 Time에서 가장 바깥쪽에 있을 필요는 없습니다.
fn axis_promotion<'l, const T: Tu>(
    input: CollectTensor<'l, T, f32, m![1], m![B], m![W, R], m![S, V, U], m![P]>,
) -> VectorFinalTensor<'l, T, f32, m![1], m![B], m![W, V], m![S, U], m![P]> {
    input
        .vector_init()
        // R을 합산하고 V를 Time에서 OutSlice로 옮깁니다.
        .vector_inter_slice_reduce::<m![W, V], m![S, U]>(InterSliceReduceOpF32::Add)
        .vector_final()
}
text
Slice = [W, R]     ->  [W, V]
Time  = [S, V, U]  ->  [S, U]

축약기(reducer)와 슬라이스 내부 체인(intra-slice chain)을 두 가지 순서로 결합하는 예제는 벡터 엔진 예제(Vector Engine Examples)를 참고하세요.

성능(Performance)

주요 튜닝 변수는 축약 비율(reduction ratio) r, 즉 하나의 축약 그룹에 속한 슬라이스(slice)의 수입니다. 슬라이스 간 축약 지연 시간(latency)은 O(r) 사이클이며, 대략 축약 그룹의 링(ring)을 한 바퀴 도는 시간입니다. 전체 실행 시간은 입력 스트리밍 시간에 이 링 크기에 해당하는 마무리 지연(tail)을 더한 값입니다.

실제로는 앞단의 작업—부분합을 만드는 수축(contraction) 연산이나 vector_inter_slice_reduce() 앞의 슬라이스 내부 연산—이 더 오래 걸리는 경우가 많아, 링의 마무리 지연(tail)이 가려지고 축약기가 병목(bottleneck)이 되지 않습니다. r이 커져 마무리 지연이 길어지거나, 텐서(tensor)가 작아 고정 지연을 여러 패킷(packet)에 분산하지 못할 때 축약기의 비용이 두드러집니다.
