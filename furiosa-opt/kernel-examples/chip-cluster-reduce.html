사례 연구: 칩과 클러스터 축약(Chip and Cluster Reduction)

칩·클러스터 축약(chip/cluster reduction)은 서로 다른 Chip 또는 Cluster 차원(dimension)에 저장된 부분 값(partial value)을 결합합니다. 예제에서는 두 차원 각각에 대해 ReduceScatter, AllGather, 이 둘의 조합, 직접 AllReduce를 구현합니다. 별도의 칩 예제에서는 나비형 전체 축약(Butterfly AllReduce)을 구현합니다.

형태 변환(Shape Transformations)

[dimension], [local] 표기는 차원 형태(dimension shape)와 각 차원 인덱스(index)의 로컬 저장 형태(local shape)를 구분합니다. R은 축약할 차원, S는 분산하거나 수집할 로컬 축(axis), P...와 Q...는 S 앞뒤의 로컬 형태라고 하겠습니다. ReduceScatter와 AllGather에서는 R과 S의 크기가 같은 N이어야 합니다. Broadcast(N)은 그 차원의 N개 인덱스가 모두 같은 값을 가진다는 뜻입니다. 표는 논리적 결과를 설명하며, 제거되지 않는 로컬 축의 순서는 유지됩니다.

연산(Operation) 형태 변환(Shape transformation)
ReduceScatter [R], [P..., S, Q...] -> [S], [P..., Q...]
AllGather [S], [P..., Q...] -> [Broadcast(N)], [P..., S, Q...]
AllReduce [R], [P...] -> [Broadcast(N)], [P...]

ReduceScatter는 R을 축약하고 결과의 S 축(axis)을 분산합니다. 차원 인덱스(dimension index) s는 S의 좌표 s에 해당하는 값을 보유합니다. AllGather는 모든 차원 인덱스에 S의 모든 좌표를 모아 이 분산을 되돌립니다. AllReduce는 로컬 형태(local shape)를 유지하면서 R을 축약하고 결과를 복제합니다. 직접 순환 축약(cyclic reduction), ReduceScatter 후 AllGather, 나비형 교환(butterfly exchange)은 모두 같은 AllReduce 형태 변환(shape transformation)을 수행합니다. 이 변환은 칩(chip) 차원과 클러스터(cluster) 차원 모두에 적용됩니다.

부동소수점 축약 순서(Floating-Point Reduction Order)

Broadcast(N)은 논리적 배치(logical placement)를 보장하는 표현입니다. 순환 축약(cyclic reduction)은 0 + 1 + 2 + 3과 1 + 2 + 3 + 0처럼 계산 순서가 달라질 수 있으므로, 독립적으로 계산한 부동소수점 복제본(floating-point replica)의 값은 조금 다를 수 있습니다. ReduceScatter 후 AllGather를 수행하면 각 조각(shard)을 한 번만 계산한 뒤 모으므로 복제본들이 동일합니다. 예제는 i32를 사용하므로 반올림 순서 문제는 적용되지 않습니다.

재분배 기본 연산(Redistribution Primitives)

예제는 지연 실행되는 SRAM 재분배 계획(redistribution plan)을 사용합니다. to_dm 앞의 섞기(shuffle)·잘라내기(slice) 단계는 DMA 하나로 융합(fuse)됩니다. 반면 asymmetric_chip_slice와 asymmetric_cluster_slice를 직접 호출하면 sub 컨텍스트(sub-context)를 사용하며, 어느 차원을 따라서도 데이터를 옮기지 않습니다.

동기화(Synchronization)

컴파일러(compiler)는 to_dm이 최종 재분배 계획(redistribution plan)을 실제로 실행할 때 그 계획으로부터 동기화(synchronization)를 도출합니다. 소스 칩(source chip)이 바뀌면 ChipSync, 소스 클러스터(source cluster)가 바뀌면 ClusterSync를 삽입합니다. 두 차원을 모두 바꾸는 융합 계획(fused plan)에는 두 동기화 프로토콜(protocol)이 모두 적용됩니다. 로컬 DmTensor의 잘라내기(slicing)에는 어느 것도 추가되지 않습니다.

컴파일러(compiler)는 원격 DMA(remote DMA) 접근 전에 목적지 준비 동기화(destination-readiness sync)를, 접근 후에는 완료 동기화(completion sync)를 생성합니다. 자기 자신으로 향하는 칩 경로(self-to-self route)는 칩 간 송수신을 생성하지 않습니다.

예제(Example) 재분배 호출(Redistribution calls) 자동 삽입되는 동기화(Synchronization)
칩 ReduceScatter(Chip ReduceScatter) chip_shuffle().chip_slice().to_dm() 체인(chain) 4개 ChipSync 프로토콜(protocol) 3개. 라운드 0은 자기 자신으로 향하고, 라운드 1~3은 칩 간에 통신합니다.
칩 AllGather(Chip AllGather) 차원을 원소로 옮기는 dimension-to-element to_dm() 1개 ChipSync 프로토콜(protocol) 1개
칩 ReduceScatter 후 AllGather ReduceScatter와 AllGather의 조합 ChipSync 프로토콜(protocol) 4개
칩 AllReduce(Chip AllReduce) chip_shuffle().to_dm() 체인(chain) 3개. 로컬 값은 이미 있습니다. ChipSync 프로토콜(protocol) 3개
칩 나비형 AllReduce(Chip Butterfly AllReduce) chip_shuffle().to_dm() 체인(chain) 2개 ChipSync 프로토콜(protocol) 2개
클러스터 ReduceScatter(Cluster ReduceScatter) 로컬 잘라내기(local slice) 2개와 cluster_swap().to_dm() 체인(chain) 1개 ClusterSync 프로토콜(protocol) 1개
클러스터 AllGather(Cluster AllGather) 차원을 원소로 옮기는 dimension-to-element to_dm() 1개 ClusterSync 프로토콜(protocol) 1개
클러스터 ReduceScatter 후 AllGather ReduceScatter와 AllGather의 조합 ClusterSync 프로토콜(protocol) 2개
클러스터 AllReduce(Cluster AllReduce) cluster_swap().to_dm() 체인(chain) 1개 ClusterSync 프로토콜(protocol) 1개

이 개수는 예제에 명시된 재분배 호출(redistribution call)을 기준으로 합니다. HBM 전송(transfer)과 로컬 벡터 엔진(Vector Engine) 작업에도 자체 의존성(dependency)이 있지만 칩·클러스터 재분배 동기화는 추가하지 않습니다.

칩 예제(Chip Examples)

예제는 칩 4개에 해당하는 A·B 축(axis)과 256바이트 [C, D] 데이터(payload)를 사용합니다. 칩(chip)과 조각(shard)의 인덱스(index)는 0~3입니다.

rust
use furiosa_opt_std::prelude::*;

axes![A = 4, B = 4, C = 8, D = 8, I = 2, X = 2];

축약(reduction) 예제들은 다음 벡터 엔진(Vector Engine) 덧셈을 공통으로 사용합니다.

rust
/// 벡터 엔진(Vector Engine)으로 두 `[C, D]` DM 텐서(tensor)를 더합니다.
pub fn add_pair(
    device: &mut Device,
    lhs: &DmTensor<i32, m![A], m![1 # 2], m![1 # 256], m![C, D]>,
    rhs: &DmTensor<i32, m![A], m![1 # 2], m![1 # 256], m![C, D]>,
    output: &mut DmTensor<i32, m![A], m![1 # 2], m![1 # 256], m![C, D]>,
) {
    device
        .main
        .begin_interleaved::<I, _, _, _, _, _>(lhs.view(), rhs.view())
        .fetch::<m![C, I], m![D]>()
        .collect::<m![C, I], m![D]>()
        .vector_init()
        .vector_intra_slice_unzip::<I, m![C]>()
        .vector_clip_zip(ClipBinaryOpI32::AddFxp)
        .vector_final()
        .commit_trim::<m![D]>()
        .commit_view(output.view_mut());
}

ReduceScatter

입력은 A를 칩(chip)에 분산하고 [B, C, D]를 로컬(local)에 둡니다. 각 chip_shuffle().chip_slice().to_dm() 체인(chain)이 B 좌표 하나를 선택하여 대상 칩으로 전달합니다. 이어지는 벡터 엔진(Vector Engine) 체인 세 개가 전달된 네 [C, D] 값을 합산합니다. 여기서 in[p, s]는 소스 칩 p가 가진 조각(shard) s의 값이며, out[s] = sum_p in[p, s]입니다.

rust
/// 칩(chip) `i`가 모든 칩의 합에서 조각(shard) `i`를 보유합니다.
#[device(chip = 4)]
pub fn reduce_scatter(
    device: &mut Device,
    hbm: &HbmTensor<i32, m![A], m![B, C, D]>,
) -> HbmTensor<i32, m![A], m![C, D]> {
    let full: DmTensor<i32, m![A], m![1 # 2], m![1 # 256], m![B, C, D]> = hbm.to_dm(&mut device.tdma);
    reduce_scatter_dm(device, &full).to_hbm(&mut device.tdma)
}
대상 칩(Target chip) 라운드(Round) 0 라운드(Round) 1 라운드(Round) 2 라운드(Round) 3 결과(Result)
0 in[0,0] in[1,0] in[2,0] in[3,0] out[0]
1 in[1,1] in[2,1] in[3,1] in[0,1] out[1]
2 in[2,2] in[3,2] in[0,2] in[1,2] out[2]
3 in[3,3] in[0,3] in[1,3] in[2,3] out[3]

결과는 조각(shard)으로 나뉜 상태를 유지합니다. 대상 칩(chip) s가 out[s]를 가집니다.

AllGather

입력에서 소스 칩(source chip) s는 [C, D] 조각(shard) 하나를 가지며 이를 in[s]로 씁니다. to_dm() 한 번이 칩 차원(chip dimension)을 로컬 원소 형태(local element shape)로 옮기고, 그 형태를 모든 칩에 브로드캐스트(broadcast)합니다.

rust
/// 모든 칩(chip)이 `A`를 따라 모든 조각(shard)을 받습니다.
#[device(chip = 4)]
pub fn all_gather(device: &mut Device, hbm: &HbmTensor<i32, m![A], m![C, D]>) -> HbmTensor<i32, m![4], m![A, C, D]> {
    let shard: DmTensor<i32, m![A], m![1 # 2], m![1 # 256], m![C, D]> = hbm.to_dm(&mut device.tdma);
    all_gather_dm::<m![A], m![A, C, D]>(&mut device.tdma, &shard).to_hbm(&mut device.tdma)
}
대상 칩(Target chip) to_dm() 이후의 로컬 원소(local element)
0 [in[0], in[1], in[2], in[3]]
1 [in[0], in[1], in[2], in[3]]
2 [in[0], in[1], in[2], in[3]]
3 [in[0], in[1], in[2], in[3]]

모든 대상(target)이 모든 조각(shard)을 받습니다.

ReduceScatter 후 AllGather

이 예제는 ReduceScatter의 결과를 AllGather에 바로 전달합니다.

rust
/// ReduceScatter와 AllGather를 결합하여 모든 칩(chip)이 축약된 조각(reduced shard)을 받게 합니다.
#[device(chip = 4)]
pub fn all_gather_after_reduce_scatter(
    device: &mut Device,
    hbm: &HbmTensor<i32, m![A], m![B, C, D]>,
) -> HbmTensor<i32, m![4], m![B, C, D]> {
    let full: DmTensor<i32, m![A], m![1 # 2], m![1 # 256], m![B, C, D]> = hbm.to_dm(&mut device.tdma);
    let shard = reduce_scatter_dm(device, &full);
    // 대상 칩(chip) b가 좌표 b를 소유하므로, 축 이름을 바꾸어도 전송 순서(wire order)는 유지됩니다.
    let shard = unsafe { shard.reshape::<m![B], m![1 # 2], m![1 # 256], m![C, D]>() };
    all_gather_dm::<m![B], m![B, C, D]>(&mut device.tdma, &shard).to_hbm(&mut device.tdma)
}

최종 배치(placement)는 위에서 본 AllGather 상태와 같습니다.

AllReduce

입력은 칩(chip) p에 형태(shape)가 [C, D]인 부분 값(partial) in[p] 하나를 줍니다. 원래 텐서(tensor)가 이동 없는 항등 회전(identity rotation)을 제공하고, 세 번의 칩 섞기(chip shuffle)가 나머지 순환 회전(cyclic rotation)을 제공합니다. 네 회전의 값을 모두 더하면 모든 대상 칩에 out[target] = sum_i in[i]가 남습니다.

rust
/// 네 번의 순환 칩 회전(cyclic chip rotation)을 합산하여 모든 칩이 완전한 축약 결과(full reduction)를 받게 합니다.
#[device(chip = 4)]
pub fn all_reduce(device: &mut Device, hbm: &HbmTensor<i32, m![A], m![C, D]>) -> HbmTensor<i32, m![A], m![C, D]> {
    let round0: DmTensor<i32, m![A], m![1 # 2], m![1 # 256], m![C, D]> = hbm.to_dm(&mut device.tdma);
    let round1 = round0.chip_shuffle([1, 2, 3, 0]).to_dm::<m![C, D]>(&mut device.tdma);
    let round2 = round0.chip_shuffle([2, 3, 0, 1]).to_dm::<m![C, D]>(&mut device.tdma);
    let round3 = round0.chip_shuffle([3, 0, 1, 2]).to_dm::<m![C, D]>(&mut device.tdma);

    let mut sum01 = DmTensor::new();
    let mut sum012 = DmTensor::new();
    let mut sum = DmTensor::new();
    add_pair(device, &round0, &round1, &mut sum01);
    add_pair(device, &round2, &sum01, &mut sum012);
    add_pair(device, &round3, &sum012, &mut sum);
    sum.to_hbm(&mut device.tdma)
}
대상 칩(Target chip) 로컬(Local) 회전(Rotation) 1 회전(Rotation) 2 회전(Rotation) 3 결과(Result)
0 in[0] in[1] in[2] in[3] out[0] = sum_i in[i]
1 in[1] in[2] in[3] in[0] out[1] = sum_i in[i]
2 in[2] in[3] in[0] in[1] out[2] = sum_i in[i]
3 in[3] in[0] in[1] in[2] out[3] = sum_i in[i]

나비형 전체 축약(Butterfly AllReduce)

입력은 칩(chip) p에 형태(shape)가 [C, D]인 부분 값(partial) in[p] 하나를 줍니다. 섞기와 덧셈(shuffle-and-add)을 두 라운드 수행하면 모든 칩에 sum_i in[i]가 남습니다. 여기서 i는 모든 소스 칩을 순회합니다.

rust
/// XOR로 짝지은 나비형 라운드(butterfly round)를 통해 칩(chip) 간 축약(reduction)을 수행합니다.
#[device(chip = 4)]
pub fn butterfly_all_reduce(
    device: &mut Device,
    hbm: &HbmTensor<i32, m![A], m![C, D]>,
) -> HbmTensor<i32, m![A], m![C, D]> {
    let partials: DmTensor<i32, m![A], m![1 # 2], m![1 # 256], m![C, D]> = hbm.to_dm(&mut device.tdma);
    let swapped = partials.chip_shuffle([1, 0, 3, 2]).to_dm::<m![C, D]>(&mut device.tdma);
    let mut first: DmTensor<i32, m![A], m![1 # 2], m![1 # 256], m![C, D]> = DmTensor::new();
    add_pair(device, &swapped, &partials, &mut first);

    let swapped = first.chip_shuffle([2, 3, 0, 1]).to_dm::<m![C, D]>(&mut device.tdma);
    let mut sum: DmTensor<i32, m![A], m![1 # 2], m![1 # 256], m![C, D]> = DmTensor::new();
    add_pair(device, &swapped, &first, &mut sum);
    sum.to_hbm(&mut device.tdma)
}
대상 칩(Target chip) 초기값(Initial) 첫 번째 상대 칩(First peer) 첫 번째 합(First sum) 두 번째 상대 칩의 합(Second peer sum) 최종값(Final)
0 in[0] in[1] in[1]+in[0] in[3]+in[2] out[0] = sum_i in[i]
1 in[1] in[0] in[0]+in[1] in[2]+in[3] out[1] = sum_i in[i]
2 in[2] in[3] in[3]+in[2] in[1]+in[0] out[2] = sum_i in[i]
3 in[3] in[2] in[2]+in[3] in[0]+in[1] out[3] = sum_i in[i]

클러스터 예제(Cluster Examples)

클러스터(cluster) 예제는 원소가 두 개인 A·B 축(axis)과 동일한 256바이트 [C, D] 데이터(payload)를 사용합니다. 클러스터와 조각(shard)의 인덱스(index)는 0~1입니다.

rust
use furiosa_opt_std::prelude::*;

axes![A = 2, B = 2, C = 8, D = 8, I = 2];

클러스터(cluster) 예제는 다음과 같이 두 클러스터에 대응하는 덧셈을 사용합니다.

rust
/// 벡터 엔진(Vector Engine)으로 두 `[C, D]` DM 텐서(tensor)를 더합니다.
pub fn add_pair(
    device: &mut Device,
    lhs: &DmTensor<i32, m![1], m![A], m![1 # 256], m![C, D]>,
    rhs: &DmTensor<i32, m![1], m![A], m![1 # 256], m![C, D]>,
    output: &mut DmTensor<i32, m![1], m![A], m![1 # 256], m![C, D]>,
) {
    device
        .main
        .begin_interleaved::<I, _, _, _, _, _>(lhs.view(), rhs.view())
        .fetch::<m![C, I], m![D]>()
        .collect::<m![C, I], m![D]>()
        .vector_init()
        .vector_intra_slice_unzip::<I, m![C]>()
        .vector_clip_zip(ClipBinaryOpI32::AddFxp)
        .vector_final()
        .commit_trim::<m![D]>()
        .commit_view(output.view_mut());
}

ReduceScatter

첫 번째 로컬 cluster_slice는 B 좌표 [0, 1]을 선택하여 클러스터(cluster)마다 값 하나를 가져옵니다. 두 번째는 [1, 0]을 선택하고, cluster_swap().to_dm()이 이 값들을 반대편 클러스터로 옮깁니다. 이어서 벡터 엔진(Vector Engine) 체인이 로컬 값과 이동한 [C, D] 값을 더합니다. 여기서 in[c, s]는 소스 클러스터 c가 가진 조각(shard) s의 값이며, out[s] = sum_c in[c, s]입니다.

rust
/// 클러스터(cluster) `i`가 두 클러스터의 합에서 조각(shard) `i`를 보유합니다.
#[device(chip = 1)]
pub fn reduce_scatter(
    device: &mut Device,
    hbm: &HbmTensor<i32, m![1], m![A, B, C, D]>,
) -> HbmTensor<i32, m![1], m![A, C, D]> {
    let full: DmTensor<i32, m![1], m![A], m![1 # 256], m![B, C, D]> = hbm.to_dm(&mut device.tdma);
    reduce_scatter_dm(device, &full).to_hbm(&mut device.tdma)
}
대상 클러스터(Target cluster) 로컬(Local) 교환 전 원격 값(Remote before swap) 교환 후 원격 값(Remote after swap) 결과(Result)
0 in[0,0] in[0,1] in[1,0] out[0]
1 in[1,1] in[1,0] in[0,1] out[1]

AllGather

입력에서 소스 클러스터(source cluster) s는 [C, D] 조각(shard) 하나를 가지며 이를 in[s]로 씁니다. to_dm() 한 번이 클러스터 차원(cluster dimension)을 로컬 원소 형태(local element shape)로 옮기고, 그 형태를 양쪽 클러스터에 브로드캐스트(broadcast)합니다.

rust
/// 두 클러스터(cluster)가 `A`를 따라 모든 조각(shard)을 받습니다.
#[device(chip = 1)]
pub fn all_gather(device: &mut Device, hbm: &HbmTensor<i32, m![1], m![A, C, D]>) -> HbmTensor<i32, m![1], m![A, C, D]> {
    let shard: DmTensor<i32, m![1], m![A], m![1 # 256], m![C, D]> = hbm.to_dm(&mut device.tdma);
    all_gather_dm::<m![A], m![A, C, D]>(&mut device.tdma, &shard).to_hbm(&mut device.tdma)
}
대상 클러스터(Target cluster) to_dm() 이후의 로컬 원소(local element)
0 [in[0], in[1]]
1 [in[0], in[1]]

ReduceScatter 후 AllGather

이 예제는 클러스터 ReduceScatter의 결과를 AllGather에 바로 전달합니다.

rust
/// ReduceScatter와 AllGather를 결합하여 두 클러스터(cluster)가 축약된 조각(reduced shard)을 받게 합니다.
#[device(chip = 1)]
pub fn all_gather_after_reduce_scatter(
    device: &mut Device,
    hbm: &HbmTensor<i32, m![1], m![A, B, C, D]>,
) -> HbmTensor<i32, m![1], m![B, C, D]> {
    let full: DmTensor<i32, m![1], m![A], m![1 # 256], m![B, C, D]> = hbm.to_dm(&mut device.tdma);
    let shard = reduce_scatter_dm(device, &full);
    // 대상 클러스터(cluster) b가 좌표 b를 소유하므로, 축 이름을 바꾸어도 전송 순서(wire order)는 유지됩니다.
    let shard = unsafe { shard.reshape::<m![1], m![B], m![1 # 256], m![C, D]>() };
    all_gather_dm::<m![B], m![B, C, D]>(&mut device.tdma, &shard).to_hbm(&mut device.tdma)
}

AllReduce

입력은 클러스터(cluster) c에 형태(shape)가 [C, D]인 부분 값(partial) in[c] 하나를 줍니다. 클러스터 교환(cluster swap) 한 번으로 두 부분 값을 교환하고, 덧셈 한 번으로 완전한 축약 결과를 양쪽 클러스터에 남깁니다.

rust
/// 로컬 부분 값(local partial)과 교환된 클러스터 부분 값을 더하여 두 클러스터가 완전한 축약 결과(full reduction)를 받게 합니다.
#[device(chip = 1)]
pub fn all_reduce(device: &mut Device, hbm: &HbmTensor<i32, m![1], m![A, C, D]>) -> HbmTensor<i32, m![1], m![A, C, D]> {
    let partials: DmTensor<i32, m![1], m![A], m![1 # 256], m![C, D]> = hbm.to_dm(&mut device.tdma);
    let remote = partials.cluster_swap().to_dm::<m![C, D]>(&mut device.tdma);

    let mut sum: DmTensor<i32, m![1], m![A], m![1 # 256], m![C, D]> = DmTensor::new();
    add_pair(device, &partials, &remote, &mut sum);
    sum.to_hbm(&mut device.tdma)
}
대상 클러스터(Target cluster) 로컬(Local) 교환한 상대 값(Swapped peer) 결과(Result)
0 in[0] in[1] out[0] = sum_i in[i]
1 in[1] in[0] out[1] = sum_i in[i]

DMA 배치 요구 사항(DMA Layout Requirements)

정렬(alignment), 실제 인덱스(live-index), 256바이트 연속 구간(contiguous-run) 요구 사항은 재분배 연산(Redistribution Operations)을 참고하세요. 예제는 m![B, C, D]를 사용하며, 안쪽 m![C, D] 구간은 정확히 256바이트의 i32 데이터입니다.
