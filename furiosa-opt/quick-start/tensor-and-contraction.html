텐서와 수축(Tensor and Contraction)

읽기 도움말 · 번역자 설명

텐서(tensor)는 여러 축(axis)으로 값을 찾는 배열입니다. 수축(contraction)은 두 텐서의 값을 곱한 뒤, 출력에서 없앨 공통 축을 따라 결과를 더해 모으는 계산입니다. 두 입력이 공유하는 축이라도 배치 축(batch axis)처럼 출력에 남는 축이 있으므로, 어떤 축을 더해 모을지 구분해야 합니다. 내적(dot product)과 행렬곱(matrix multiplication)이 대표적인 예입니다.

텐서(tensor)는 자신의 형상(shape)에 속하는, 축 이름으로 지정된 각 인덱스(index)를 하나의 값에 대응시킵니다. 형상은 이름이 붙은 축(axis)의 순서 없는 집합이므로, { N = 4, C = 3 }과 { C = 3, N = 4 }는 같은 텐서를 나타냅니다. 이 형상을 순서가 있는 형태로 표현하면 익숙한 다차원 배열(multidimensional array)처럼 동작합니다. 텐서 인덱스는 모든 축에 대해 하나씩 좌푯값을 지정합니다. 따라서 { N = 4, C = 3 }에는 { N: 0, C: 0 }, { N: 0, C: 1 } 같은 인덱스가 포함됩니다.

텐서(Tensor) 차원(Dimension) 예시(Example) 이름이 있는 형상(Named shape)
스칼라(Scalar) 0D 5.2 {}
벡터(Vector) 1D [1, 2, 3] { I = 3 }
행렬(Matrix) 2D 2 × 4 격자(grid) { I = 2, J = 4 }
이미지 배치(Image batch) 4D RGB 이미지 네 장 { N = 4, C = 3, H = 256, W = 512 }

텐서 수축(tensor contraction)은 두 입력을 원소별(elementwise)로 곱한 뒤, 두 입력에 공통으로 존재하지만 출력에는 없는 모든 축(axis)을 축약(reduce)합니다. 모든 수축은 브로드캐스트(broadcast), 곱셈(multiply), 축약(reduce) 단계로 구성됩니다.

연산(Operation) 아인슈타인 합 표기(Einsum) 브로드캐스트(Broadcast) 곱셈(Multiply) 축약(Reduce)
내적(Dot product) I, I \rightarrow 1 없음. x_i y_i \sum_i x_i y_i
GEMV IJ, J \rightarrow I x를 I에 걸쳐 브로드캐스트(broadcast)합니다. A_{ij} x_j y_i = \sum_j A_{ij} x_j
GEMM IK, KJ \rightarrow IJ A는 J에 걸쳐, B는 I에 걸쳐 브로드캐스트(broadcast)합니다. A_{ik} B_{kj} C_{ij} = \sum_k A_{ik} B_{kj}

이 페이지에서는 입문에 필요한 수학만 다룹니다. 매핑(mapping), 이동(movement), 엔진(engine)의 동작 규칙(contract)은 각각의 참조 장에서 설명합니다.
