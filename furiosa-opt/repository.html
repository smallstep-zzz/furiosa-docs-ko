Furiosa 최적화 도구(Furiosa Optimizer)

Furiosa NPU 최적화 도구(optimizer)를 위한 크레이트(crate) 모음입니다.

저장소 구조(Repository Structure)

text
furiosa-opt/
├── furiosa-mapping/
├── furiosa-mapping-macro/
├── furiosa-opt-macro/
├── furiosa-opt-std/
├── furiosa-opt-examples/
└── docs/

환경 구성(Setup)

사전 요구 사항(Prerequisites)

모든 백엔드(backend)에서 지원하는 호스트(host)는 x86_64-unknown-linux-gnu뿐입니다. cargo-furiosa-opt 실행 파일(binary)과 furiosa-mapping·furiosa-opt-lower가 빌드(build) 중 가져오는 정적 라이브러리(static library)는 이 대상(target)용으로만 배포됩니다.

Ubuntu(jammy / noble / resolute)

사용 가능한 가장 오래된 릴리스(release)는 22.04입니다. cargo-furiosa-opt와 furiosa-opt-driver는 GLIBC_2.34가 필요한데, 20.04는 2.31을 제공하므로 실행되지 않습니다.

bash
sudo apt install build-essential libclang-dev   # 모든 백엔드(backend)에 필요합니다.
sudo apt install gcc-aarch64-linux-gnu          # NPU 빌드(cargo furiosa-opt)에만 필요합니다.
  • build-essential: rustc는 시스템의 cc로 호스트 실행 파일(host binary)을 링크(link)합니다. Rust 도구 모음(toolchain)은 cc를 제공하지 않습니다.
  • libclang-dev: 컴파일러 도구 모음(compiler toolchain)이 libclang.so를 적재(load)합니다.
  • gcc-aarch64-linux-gnu: aarch64-linux-gnu-{gcc,as,ld,objcopy}가 NPU용 ELF 프로그램을 생성합니다.

macOS(Apple silicon)

macOS는 아직 지원하지 않습니다. Linux x86-64 컨테이너(container) 안에서 작업하세요. 산출물(artifact)이 x86-64용으로만 배포되므로 arm64 컨테이너도 지원하지 않습니다.

bash
docker run --platform linux/amd64 -it ubuntu:22.04

Apple silicon에서는 컨테이너 런타임(container runtime)의 Rosetta 백엔드(backend)를 켜면 네이티브(native)에 가까운 x86-64 속도를 얻을 수 있습니다. 그런 다음 컨테이너 안에서 Ubuntu 절차를 따르세요.

설치(Install)

cargo-furiosa-opt는 rustc 드라이버(driver)이며, 특정 rustc nightly 버전의 ABI에 고정되어 있습니다. rust-toolchain.toml에도 고정된 동일한 도구 모음(toolchain)을 설치하고 cargo-binstall로 실행 파일(binary)을 설치하세요.

bash
rustup toolchain install nightly-2026-05-01
cargo +nightly-2026-05-01 install cargo-binstall
cargo +nightly-2026-05-01 binstall cargo-furiosa-opt

cargo 하위 명령(subcommand)으로 실행합니다.

bash
cargo furiosa-opt test --test mnist_tests

빌드와 테스트(Build and Test)

bash
make check    # cargo check --workspace --all-targets
make fmt      # cargo fmt --all -- --check
make clippy   # cargo clippy --workspace --all-targets -- -D warnings
make test     # cargo test --workspace --release

런타임(Runtime)

런타임(runtime) 구현은 furiosa-opt-rt 런타임 가이드를 참고하세요.

문서(Documentation)

bash
make mdbook-install   # mdbook과 플러그인(plugin)을 설치합니다.
make mdbook-serve     # 문서(docs)를 로컬에서 제공합니다.
make mdbook-build     # 정적 HTML(static HTML)을 빌드합니다.
make mdbook-test      # mdbook의 코드 블록(code block)을 테스트합니다.

개발 도구(Tooling)

언어 서버(Language Server)

furiosa-rust-analyzer-proxy는 매핑 표현식(mapping expression) 지원을 강화하여 표준 Rust IDE 기능을 제공하는 rust-analyzer 프록시(proxy)입니다. 일반 Rust 언어 서버(language server) 동작은 rust-analyzer에 맡기고, 편집기에 보낼 결과를 다시 작성합니다. 따라서 Stride<Symbol<A>, 8>처럼 긴 자료형(type)을 m![A / 8]처럼 읽기 쉬운 매핑 표현식으로 볼 수 있습니다.

설치와 설정은 언어 서버 문서(Language Server documentation)를 참고하세요.

스케줄 뷰어(Schedule Viewer)

스케줄 뷰어(Schedule Viewer)는 실행 타임라인(execution timeline)을 시각화하여 성능 병목(performance bottleneck)을 찾도록 돕습니다. furiosa-opt로 스케줄 JSON 파일을 내보낸 뒤 furiosa-schedule-viewer로 여세요.

설치와 사용법은 스케줄 뷰어 문서(Schedule Viewer documentation)를 참고하세요.
