스케줄 뷰어(Schedule Viewer)

스케줄 뷰어(Schedule Viewer)는 스케줄 컴파일(schedule compilation)과 조건이 고정된 후보(candidate) 사이의 전체 완료 시간(makespan) 비교를 지원합니다. 뷰어는 정적 실행 계획(static execution plan)을 보여 주며, 값이나 처리량(throughput)을 검증하지는 않습니다.

스케줄 뷰어(Schedule Viewer)는 cargo furiosa-opt가 생성한 스케줄 JSON 파일을 읽어 대화형 실행 타임라인(interactive execution timeline)으로 표시합니다. 빠른 시작(Quick Start)은 개발 도구의 하나로 뷰어를 소개하며, 이 절은 설치와 스케줄 확인 방법을 설명합니다. 어떤 연산이 병렬 실행되는지, 각 연산이 어느 컨텍스트(context)나 자원(resource)을 점유하는지, 어떤 연산이 파이프라인(pipeline) 진행을 막는지 살펴보세요.

스케줄 검토하기(Review a Schedule)

고정된 커널 작업(kernel workload)을 비교할 때는 마지막 예정 사이클(cycle)인 스케줄 전체 완료 시간(schedule makespan)을 사용합니다. 후보 간에 릴리스(release), 형태(shape), 자료형(data type), 매핑(mapping)을 유지하세요. 타임라인(timeline)으로 실행 겹침(overlap), 의존성(dependency), 자원 점유(resource occupancy)의 차이를 설명합니다.

시작하기(Getting Started)

뷰어 설치·실행(Install and Run the Viewer)

crates.io에서 furiosa-schedule-viewer 실행 파일(binary)을 설치합니다.

bash
cargo install furiosa-schedule-viewer

뷰어(viewer)를 실행하여 로컬 웹 UI(local web UI)를 시작합니다.

bash
furiosa-schedule-viewer

서버(server)는 기본적으로 127.0.0.1:9254에 연결(bind)하고 기본 브라우저(default browser)로 페이지를 엽니다. 서버가 요청을 받을 주소(listen address)는 --host와 --port로 바꿀 수 있습니다.

bash
furiosa-schedule-viewer --host 127.0.0.1 --port 9254

스케줄 JSON 파일 생성하기(Generate a Schedule JSON File)

--dump-schedule은 컴파일된 스케줄(schedule)을 JSON 파일로 저장합니다. cargo furiosa-opt compile로 커널(kernel) 하나를 컴파일할 때 사용할 수 있습니다.

bash
cargo furiosa-opt compile <device-function> \
  --dump-schedule <path-to-json-file>

함수 이름(function name)을 위치 인수인 필터(filter)로 전달하세요. 이름이 모호하면 kernel::gemm_kernel::gemm_kernel 같은 전체 Rust 경로(full Rust path)를 사용합니다. 이 명령은 일반 커널 산출물(kernel artifact)도 그대로 생성합니다. JSON 파일이 스케줄 뷰어(Schedule Viewer)의 입력입니다.

사용법(Usage)

파일 놓기 영역(drop zone)을 클릭하거나 스케줄 JSON 파일을 페이지로 끌어다 놓으면 시각화(visualization)됩니다.

텐서와 연산자 살펴보기(Inspect Tensors and Operators)

노드(node)를 클릭하면 내용을 살펴볼 수 있습니다. 왼쪽 사이드바(sidebar)에 이름(name), 수명(lifetime), 컨텍스트(context), 연결된 노드 등의 세부 정보가 나타납니다.

노드(node)에 마우스를 올리거나 선택하면 관련 노드가 강조됩니다. 예를 들어 연산자(operator)를 선택하면 입력·출력 텐서(tensor)가 강조되고, 텐서를 선택하면 그 텐서에 연결된 연산자들이 강조됩니다.

텐서(tensor)와 연산자(operator)는 실제 하드웨어 명령(hardware instruction)을 기준으로 하므로 vISA에서 정의한 것과 다를 수 있습니다. 가능한 경우 스케줄 뷰어(Schedule Viewer)는 vISA 텐서의 이름과 형태(shape), 연산자의 vISA 코드 조각(code snippet)을 함께 표시합니다.

스케줄 확대하기(Zoom In on the Schedule)

스케줄(schedule)을 확대하여 특정 구간(region)을 자세히 살펴볼 수 있습니다.

사이클 범위(cycle range)만 바꾸려면 위쪽 타임라인(timeline)을 드래그하거나 오른쪽 위의 Cycle Range 입력란을 사용합니다. 메모리 주소 범위(memory-address range)를 바꾸려면 Enable Brush를 클릭한 뒤 스케줄 화면을 드래그합니다. 브러시(brush)는 사이클 범위와 메모리 주소 범위를 함께 설정합니다.

전체 스케줄(schedule) 화면으로 돌아가려면 타임라인(timeline)의 배경을 클릭하거나 오른쪽 위의 Reset을 클릭합니다.
