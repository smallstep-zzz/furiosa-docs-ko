Furiosa-LLM#

Furiosa-LLM은 대규모 언어 모델(LLM)과 멀티모달(Vision-Language) 모델을 위한 고성능 추론 엔진입니다. 효율적인 서빙과 다양한 최적화 기능을 제공합니다. 주요 기능은 다음과 같습니다.

  • vLLM 호환 API (LLM, LLMEngine, AsyncLLMEngine API)

  • 텍스트 및 멀티모달(Vision-Language) 서빙

  • 생성 및 pooling 모델 지원 (embedding, reranking, classification)

  • PagedAttention을 이용한 효율적인 KV Cache 관리

  • 공통 프롬프트 접두부를 재사용하는 Radix-tree Prefix Caching

  • KV Cache를 호스트 메모리로 offloading하는 Hierarchical Prefix Caching (HiCache) (실험적 기능)

  • Sliding-window attention과 global attention을 혼합한 모델을 위한 Hybrid KV Cache

  • 들어오는 요청에 대한 Continuous Batching

  • CPU 배치 준비와 NPU 실행을 겹치는 Overlap Scheduling (실험적 기능)

  • Quantization: INT4, INT8, BF16, FP8, MXFP4, NVFP4

  • 여러 NPU에 걸친 data, tensor, pipeline parallelism 지원

  • Chat Completions 및 Responses API를 제공하는 OpenAI 호환 API 서버

  • 다양한 decoding 알고리즘: greedy search, top-k/top-p, speculative decoding (예정)

  • Tool calling 및 reasoning parser 지원

  • Structured output 생성 (choice, regex, JSON schema, grammar)

  • Prefill과 decode를 혼합 배치하는 Chunked Prefill

  • 서빙 상태 관찰을 위한 Prometheus metrics endpoint

  • Hugging Face 모델 연동 및 Hub 지원
