BGE-M3#

BGE-M3는 BAAI에서 개발한 XLM-RoBERTa 인코더 아키텍처 기반의 다국어 텍스트 임베딩 모델입니다. 이 모델은 밀집, 희소, 다중 벡터 검색을 통합합니다. Furiosa-LLM은 1,024차원의, CLS-pooled 밀집 임베딩을 제공하여 의미 검색, 검색 및 유사성 매칭에 사용됩니다.

FuriosaAI publishes a BF16 build of BGE-M3 under the furiosa-ai organization on the Hugging Face Hub, shipping a Furiosa Executable Bundle (FXB) for running it on FuriosaAI RNGD with Furiosa-LLM. The base model also runs on other frameworks (such as FlagEmbedding, Sentence Transformers, and Transformers); for usage with those, see the upstream model card linked below.

다국어 밀집 텍스트 임베딩 (Multilingual dense text embedding)

  • 아키텍처: XLM-RoBERTa (밀집 인코더), XLMRobertaModel

  • 작업: 임베딩 (Embedding)

  • 양자화: FuriosaAI 빌드는 낮은 비트 양자화 스킴 없이 BF16 가중치를 사용합니다.

사용법#

Furiosa-LLM로 이 모델을 실행하려면 아래 예제를 따르십시오. Furiosa-LLM 및 그 전제 조건 설치모델은 OpenAI 호환 서버를 통해 온라인으로 또는 Furiosa-LLM, Python, API를 통해 오프라인으로 사용할 수 있습니다.

서버 시작#

다음 명령어를 사용하여 모델을 실행합니다: furiosa-ai/<repo> 식별자를 사용하여 모델을 실행합니다.

# Launch the server, listening on port 8000 by default
furiosa-llm serve furiosa-ai/bge-m3

서버가 준비되면 다음과 같은 메시지를 확인합니다:

INFO:     Started server process [27507]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)

기본 사용법#

서버는 OpenAI와 호환되는 /v1/embeddings 엔드포인트를 노출합니다. BGE-M3는 쿼리에 대한 지시어 프리픽스가 필요하지 않습니다. curl을 사용하여 밀집된 임베딩을 요청합니다:

curl http://localhost:8000/v1/embeddings \
    -H "Content-Type: application/json" \
    -d '{
    "model": "furiosa-ai/bge-m3",
    "input": [
      "What is BGE-M3?",
      "BGE-M3 is a multilingual text-embedding model."
    ]
    }' \
    | python -m json.tool

엔드포인트가 OpenAI와 호환되므로 OpenAI Python 클라이언트를 사용할 수도 있습니다:

from openai import OpenAI

client = OpenAI(base_url="http://localhost:8000/v1", api_key="EMPTY")

response = client.embeddings.create(
    model="furiosa-ai/bge-m3",
    input=[
        "What is BGE-M3?",
        "BGE-M3 is a multilingual text-embedding model.",
    ],
)

for data in response.data:
    print(f"Index {data.index}: {len(data.embedding)} dimensions")

고급 사용법#

오프라인 사용을 위해, LLM 생성자를 사용하여 모델을 로드합니다 (리포트에 포함된 FXB는 자동으로 감지됩니다) 및 embed를 호출하여 L2-정규화된 밀집 벡터를 얻습니다. 따라서 이들의 내적은 코사인 유사성을 나타냅니다:

from furiosa_llm import LLM

texts = [
    "What is BGE-M3?",
    "BGE-M3 is a multilingual text-embedding model.",
]

with LLM("furiosa-ai/bge-m3") as llm:
    outputs = llm.embed(texts)
    embeddings = [output.outputs.embedding for output in outputs]

similarity = sum(a * b for a, b in zip(*embeddings, strict=True))
print(f"Cosine similarity: {similarity:.4f}")
