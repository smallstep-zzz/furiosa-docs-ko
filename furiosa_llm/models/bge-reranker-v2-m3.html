BGE 레랑커 v2 M3#

BGE 레랑커 v2 M3 XLM-RoBERTa Encoder 아키텍처에 BAAI에 의해 개발 된 다국어 cross-encoder reranking 모델입니다. 쿼리 및 후보 문서 세트를 제공, 그것은 reorder retrieval 결과에 사용 된 relevance 점수를 생산 - retrieval-augmented 세대 (RAG) 및 검색 파이프라인의 일반적인 두 번째 단계.

FuriosaAI는 상류 모형을 아래에 발행합니다 furiosa-ai 구성 요소가 Hugging Face 허브에 연결됨, Furiosa 실행 가능한 번들 (FXB)를 배송하여 실행 FuriosaAI RNGD Furiosa-LLM로. 동일한 상류 무게는 또한 다른 기구 ( FlagEmbedding, Sentence 변압기 및 변압기와 같은); 그와 함께 사용을 위해, 아래에 연결되는 상류 모형 카드를 보십시오.

관련 BGE embedding 모델 참조 BGE-M3; 다른 재순위 방식에 대해서는 Qwen3-Reranker.

다국어 cross-encoder 재순위

  • 건축: XLM-RoBERTa (밀집 인코더), XLMRobertaForSequenceClassification

  • 임무: Reranking

  • 입력 / 출력: 텍스트 (query-document 쌍) / 관련 점수

  • Quantization: lower-bit quantization는 적용되지 않습니다. 상류 체크 포인트는 FP32 무게를 저장합니다; Furiosa-LLM는 FXB에 의해 실행되는 W16A16를 위한 BF16에 아래로 던집니다.

사용#

Furiosa-LLM로 이 모델을 실행하려면 아래 예제를 따르십시오. Furiosa-LLM 및 그 전제 조건 설치모델은 OpenAI 호환 서버를 통해 온라인으로 또는 Furiosa-LLM, Python, API를 통해 오프라인으로 사용할 수 있습니다.

서버를 시작하세요#

모델을 실행하려면, 매칭을 위한 furiosa-ai/<repo> 식별자:

# Launch the server, listening on port 8000 by default
furiosa-llm serve furiosa-ai/bge-reranker-v2-m3

서버가 준비되면 다음을 볼 수 있습니다.

INFO:     Started server process [27507]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)

기본 사용#

서버는 /v1/rerank Cohere 및 Jina rerank API와 호환되는 엔드포인트. 쿼리 및 후보 문서를 보내 curl; 서버는 sigmoid-normalized에 의해 주문된 문서를 반환합니다 relevance_score:

curl http://localhost:8000/v1/rerank \
    -H "Content-Type: application/json" \
    -d '{
    "model": "furiosa-ai/bge-reranker-v2-m3",
    "query": "What is deep learning?",
    "documents": [
        "Deep learning is a subset of machine learning using neural networks.",
        "Python is a popular programming language for data science.",
        "Neural networks are inspired by biological neural networks."
    ]
    }' \
    | python -m json.tool

지나갈 수 있어 top_n 가장 관련 문서만 보관하기 위해. query-document 쌍을 reranking 대신 직접 점수하려면 서버는 또한 노출 /v1/score 끝점

발전 된 사용#

오프라인 사용을 위해, 모형을 가진 적재하십시오 LLM constructor (Repo에서 발송되는 FXB는 자동적으로 발견됩니다)와 호출 score 쿼리 및 후보 문서로 relevance 점수를 얻는:

from furiosa_llm import LLM

query = "What is deep learning?"
documents = [
    "Deep learning is a subset of machine learning using neural networks.",
    "Python is a popular programming language for data science.",
]

with LLM("furiosa-ai/bge-reranker-v2-m3") as llm:
    outputs = llm.score(query, documents)
    for document, output in zip(documents, outputs, strict=True):
        print(f"score={output.outputs.score:.4f}  {document}")
