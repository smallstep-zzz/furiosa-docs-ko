EXAONE 4.5#

EXAONE 4.5는 LG AI Research의 오픈 웨이트 비전-언어 모델입니다. 이미지와 텍스트를 처리하기 위해, 덴스 EXAONE 4 언어 모델 아키텍처와 함께 전용 비전 인코더를 통합하며, 하이브리드 추론 및 도구 호출을 지원합니다.

Furiosa-LLM runs EXAONE 4.5 using the upstream FP8 release. Selected linear weights use static FP8 quantization with dynamic per-token FP8 activation quantization, while the vision encoder and attention projections stay in higher precision. FuriosaAI publishes a pre-compiled build under the furiosa-ai organization on the Hugging Face Hub, shipping a Furiosa Executable Bundle (FXB) for running the model on FuriosaAI RNGD with Furiosa-LLM. The same upstream weights also run on other frameworks (such as vLLM, SGLang, and Transformers); for usage with those, see the upstream model card linked below.

33B 밀집 형태의 비전-언어 모델; 기본적으로 추론 수행

  • 입력 / 출력: 이미지 + 텍스트 / 텍스트

  • 양자화: 선택된 선형 가중치를 FP8로 양자화 (정적, 채널별), 업스트림의 FP8 릴리스를 따르며, 활성화 값은 런타임에 동적 토큰별 FP8 양자화를 사용합니다. 업스트림 구성에서는 비전 인코더, 어텐션 프로젝션, LM 헤드, MTP 어텐션 프로젝션이 FP8 양자화에서 제외됩니다. KV 캐시는 16비트 정밀도를 유지합니다.

사용법#

Furiosa-LLM를 사용하여이 모델을 실행하려면 아래 예제 명령을 따르십시오 Furiosa-LLM 및 그 전제 조건 설치.

서버 시작#

기본적으로 EXAONE 4.5 이유를 설정하고 생각을 전환 할 수 있습니다 (see) 발전 된 사용). 서버를 시작하고 qwen3 파서가 너무 생각의 체인이 최종 답변에서 분리되어 있다고 생각했습니다.

# Launch the server, listening on port 8000 by default
furiosa-llm serve furiosa-ai/EXAONE-4.5-33B-FP8 \
  --reasoning-parser qwen3

또한 도구 (기능) 호출을 활성화하려면, 추가 hermes tool-call 파서 사용; 유지 --reasoning-parser qwen3 그래서 생각은 여전히 자신의 필드에 패러다임 :

furiosa-llm serve furiosa-ai/EXAONE-4.5-33B-FP8 \
  --reasoning-parser qwen3 \
  --enable-auto-tool-choice \
  --tool-call-parser hermes

서버가 준비되면 다음과 같은 메시지를 확인합니다:

INFO:     Started server process [27507]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)

기본 사용법#

서버는 OpenAI와 호환되는 API를 노출합니다. curl을 사용하여 텍스트 기반 요청을 보낼 수 있습니다:

curl http://localhost:8000/v1/chat/completions \
    -H "Content-Type: application/json" \
    -d '{
    "model": "furiosa-ai/EXAONE-4.5-33B-FP8",
    "messages": [{"role": "user", "content": "What is the capital of France?"}]
    }' \
    | python -m json.tool

이미지를 요청하려면 메시지에 image_url 콘텐츠 부분을 포함합니다:

curl http://localhost:8000/v1/chat/completions \
    -H "Content-Type: application/json" \
    -d '{
    "model": "furiosa-ai/EXAONE-4.5-33B-FP8",
    "messages": [{
        "role": "user",
        "content": [
            {"type": "image_url", "image_url": {"url": "https://github.com/LG-AI-EXAONE/EXAONE-4.5/blob/main/assets/exaone45_input1.jpg?raw=true"}},
            {"type": "text", "text": "What dish is the person preparing?"}
        ]
    }]
    }' \
    | python -m json.tool

The image_url.url 필드는 원격 연결을 허용합니다. http:///https:// URL, 즉, 내장된 base64 data: URL, 또는 지역 file:// 경로 (마지막 단계에서는 --allowed-local-media-path 아래에 설명된 깃발 발전 된 사용).

그리고 --reasoning-parser qwen3, EXAONE 4.5는 마지막 대답에서 따로따로 그것의 reasoning를 돌려보냅니다:

  • response.choices[].message.reasoning (스트리밍 미사용)

  • response.choices[].delta.reasoning (스트리밍 사용)

from openai import OpenAI

client = OpenAI(base_url="http://localhost:8000/v1", api_key="EMPTY")

response = client.chat.completions.create(
    model="furiosa-ai/EXAONE-4.5-33B-FP8",
    messages=[{"role": "user", "content": "How many r's are in 'strawberry'?"}],
)

print("Reasoning:", response.choices[0].message.reasoning)
print("Answer:", response.choices[0].message.content)

참고: reasoning 필드는 OpenAI API 사양에 포함되지 않지만, 널리 사용되는 관례입니다 (OpenAI Agents SDK, vLLM 등). 이 필드는 추론 내용을 포함하는 응답에서만 나타나며, 그렇지 않으면 AttributeError가 발생합니다.

고급 사용법#

멀티모달 서비스 옵션. 이 예제는 /srv/media 아래의 로컬 이미지를 허용하고, 원격 이미지 가져오기를 cdn.example.com으로 제한하며, 각 요청당 4개의 이미지를 제한합니다:

furiosa-llm serve furiosa-ai/EXAONE-4.5-33B-FP8 \
  --reasoning-parser qwen3 \
  --allowed-local-media-path /srv/media \
  --allowed-media-domains cdn.example.com \
  --image-limit-per-prompt 4

Vision-Language Models 가이드의 "서버 옵션" 섹션을 참조하여 전체 옵션 및 기본값을 확인하십시오.

이미지 처리 옵션. 이 예제는 10초의 HTTP 이미지 가져오기 타임아웃을 설정하고, min_pixels 및 max_pixels를 사용하여 이미지 크기 조정 범위를 제한합니다:

furiosa-llm serve furiosa-ai/EXAONE-4.5-33B-FP8 \
  --reasoning-parser qwen3 \
  --media-io-kwargs '{"image": {"timeout": 10}}' \
  --mm-processor-kwargs '{"min_pixels": 4096, "max_pixels": 200704}'

지원되는 값, 크기 조정 동작, 그리고 요청별 오버라이드에 대한 자세한 내용은 "멀티모달 옵션" (Vision-Language Models 가이드)을 참조하십시오.

추론 기능을 끄기. EXAONE 4.5 버전에서 기본적으로 켜져 있습니다. 단일 요청에 대해 추론 기능을 끄려면 enable_thinking을 chat_template_kwargs에 전달합니다. 이 경우 응답에는 추론 내용이 포함되지 않으므로, message.content만 읽을 수 있습니다.

# Disable thinking for a single request
response = client.chat.completions.create(
    model="furiosa-ai/EXAONE-4.5-33B-FP8",
    messages=[{"role": "user", "content": "What is the capital of France?"}],
    extra_body={"chat_template_kwargs": {"enable_thinking": False}},
)
print(response.choices[0].message.content)

모든 요청을 기본적으로 추론 기능을 끄도록 설정하려면, 서버를 --default-chat-template-kwargs 옵션으로 시작합니다 (하지만 개별 요청은 자체 chat_template_kwargs를 사용하여 추론 기능을 다시 활성화할 수 있습니다).

furiosa-llm serve furiosa-ai/EXAONE-4.5-33B-FP8 \
  --reasoning-parser qwen3 \
  --default-chat-template-kwargs '{"enable_thinking": false}'

도구 호출. 서버를 [구체적인 정보 삽입]을 사용하여 시작할 때 --enable-auto-tool-choice --tool-call-parser hermes ( 참조) 서버를 시작하세요), 통과 tools 요청에서 모델을 결정할 때 호출합니다. 참조 도구 호출 가이드 tool-choice 옵션에 대한 완벽한 클라이언트 예 및 세부 사항.
