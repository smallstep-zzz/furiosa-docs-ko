미스트랄 네모#

미스트랄 네모 12B instruction-tuned, auto-regressive dense 변압기는 assistant-style 텍스트 생성을 위한 Mistral AI와 NVIDIA에 의해 합동으로 개발된.

Furiosa-LLM Mistral NeMo를 실행합니다. FP8 RedHatAI의 정량화 된 릴리스 (동적 인 FP8 무게 FP8 활성화 quantization; KV cache는 16-bit 정밀도에서 유지)를 사용하여. FuriosaAI는 pre-compiled 빌드를 게시 furiosa-ai 구성 요소가 Hugging Face 허브에 연결됨, Furiosa 실행 가능한 번들 (FXB)를 배송하여 실행 FuriosaAI RNGD Furiosa-LLM로. 동일한 무게는 또한 다른 기구 (vLLM, SGLang 및 변압기와 같은); 그와 함께 사용을 위해, 아래에 연결되는 상류 모형 카드를 보십시오.

  • Quantization: 선형 (Transformer 구획) 무게는 quantized 입니다 FP8 (정적) 및 활성화에 사용 동적 FP8 quantization runtime (per-token, 오프라인 보정 없이). KV cache는 16-bit 정밀도에 체재합니다.

사용#

Furiosa-LLM를 사용하여이 모델을 실행하려면 아래 예제 명령을 따르십시오 Furiosa-LLM 및 그 전제 조건 설치.

서버를 시작하세요#

모델을 봉사하는 가장 간단한 방법은 다음과 같습니다.

# Launch the server, listening on port 8000 by default
furiosa-llm serve furiosa-ai/Mistral-Nemo-Instruct-2407-FP8

서버가 준비되면 다음을 볼 수 있습니다.

INFO:     Started server process [27507]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)

기본 사용#

서버는 OpenAI 호환 API를 노출합니다. 요청을 보낼 수 있습니다. curl:

curl http://localhost:8000/v1/chat/completions \
    -H "Content-Type: application/json" \
    -d '{
    "model": "furiosa-ai/Mistral-Nemo-Instruct-2407-FP8",
    "messages": [{"role": "user", "content": "What is the capital of France?"}]
    }' \
    | python -m json.tool

발전 된 사용#

Mistral-Nemo-Instruct-2407-FP8는 non-reasoning 채팅 모델이며, 파서 또는 model-specific chat-template 플래그가 필요하지 않습니다. 일반 서빙 옵션의 경우, Furiosa-LLM 서버 가이드.
