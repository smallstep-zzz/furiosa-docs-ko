Qwen3-MoE#

Qwen3 Mixture-of-Experts (MoE) 모델은 총 30.5B 개의 파라미터를 가진 자가 회귀 MoE 트랜스포머로, 토큰당 약 3.3B 개의 파라미터가 활성화됩니다. 이 모델은 강력한 지시 따르기, 텍스트 기반 추론, 다국어 지원, 그리고 도구 사용 능력을 제공합니다. 원래 하이브리드 사고/비 사고 버전뿐만 아니라, 업데이트된 instruct, thinking, 그리고 코딩 전문 버전도 제공됩니다.

Furiosa-LLM runs the Qwen3-MoE models in FP8 (static FP8 weights with dynamic FP8 activation quantization; the KV cache stays in 16-bit precision). FuriosaAI publishes pre-compiled FP8 builds under the furiosa-ai organization on the Hugging Face Hub, each shipping a Furiosa Executable Bundle (FXB) for running it on FuriosaAI RNGD with Furiosa-LLM. The same upstream weights also run on other frameworks (such as vLLM, SGLang, and Transformers); for usage with those, see the upstream model cards linked below.

Dense Qwen3 챗 모델은 Qwen3 (dense)를 참조하십시오.

사용법#

Furiosa-LLM와 함께 이 모델을 실행하려면, 다음의 예제 명령을 따르십시오. Furiosa-LLM 및 그 전제 조건 설치.

서버 시작#

furiosa-ai/<repo> 식별자를 전달합니다. 각 변형은 4개의 RNGD 카드를 사용하여 실행되며 (텐서-병렬 크기는 32개의 PE) 다음과 같은 예시를 사용합니다. 여기서는 기본적으로 추론을 수행하고, 필요에 따라 추론을 켜고 끌 수 있는 하이브리드 Qwen3-30B-A3B-FP8 모델을 사용합니다 (고급 사용법 참조).

qwen3 reasoning parser를 사용하여 추론 결과를 별도의 필드에 반환합니다. 이렇게 하면 추론 체인을 별도로 얻을 수 있습니다.

furiosa-llm serve furiosa-ai/Qwen3-30B-A3B-FP8 \
  --reasoning-parser qwen3

도구 (함수) 호출 기능을 활성화하려면 hermes tool-call parser (Qwen3 시리즈에서 사용되는 파서)를 추가합니다.

furiosa-llm serve furiosa-ai/Qwen3-30B-A3B-FP8 \
  --reasoning-parser qwen3 \
  --enable-auto-tool-choice \
  --tool-call-parser hermes

다른 변형은 동일한 방식으로 실행되지만, 한 가지 차이점이 있습니다. Qwen3-30B-A3B-Thinking-2507-FP8 변형은 항상 추론을 수행합니다 (--reasoning-parser qwen3 옵션을 사용). 반면, 추론을 수행하지 않는 Qwen3-30B-A3B-Instruct-2507-FP8 및 Qwen3-Coder-30B-A3B-Instruct-FP8 변형은 추론 파서를 제외합니다.

furiosa-llm serve furiosa-ai/Qwen3-30B-A3B-Instruct-2507-FP8

서버가 준비되면 다음과 같은 메시지를 확인합니다:

기본 사용법#

서버는 OpenAI와 호환되는 API를 노출합니다. curl을 사용하여 요청을 보낼 수 있습니다 (모델 ID를 실행한 변종으로 대체):

curl http://localhost:8000/v1/chat/completions \
    -H "Content-Type: application/json" \
    -d '{
    "model": "furiosa-ai/Qwen3-30B-A3B-FP8",
    "messages": [{"role": "user", "content": "What is the capital of France?"}]
    }' \
    | python -m json.tool

추론을 수행하는 변형 (Qwen3-30B-A3B-FP8 및 Qwen3-30B-A3B-Thinking-2507-FP8)은 최종 답변과 추론 결과를 별도로 반환합니다.

  • response.choices[].message.reasoning (스트리밍 미사용)

  • response.choices[].delta.reasoning (스트리밍 사용)

from openai import OpenAI

client = OpenAI(base_url="http://localhost:8000/v1", api_key="EMPTY")

response = client.chat.completions.create(
    model="furiosa-ai/Qwen3-30B-A3B-FP8",
    messages=[{"role": "user", "content": "How many r's are in 'strawberry'?"}],
)

print("Reasoning:", response.choices[0].message.reasoning)
print("Answer:", response.choices[0].message.content)

참고: reasoning 필드는 OpenAI API 사양에 포함되지 않지만, 널리 사용되는 관례입니다 (OpenAI Agents SDK, vLLM 등). 이 필드는 추론 내용을 포함하는 응답에서만 나타나며, 그렇지 않으면 AttributeError가 발생합니다.

고급 사용법#

추론 켜기/끄기. enable_thinking 매개변수를 chat_template_kwargs를 통해 전달하여, 하이브리드 Qwen3-30B-A3B-FP8 모델만 추론을 켜고 끌 수 있습니다. 기본적으로 추론을 수행합니다. 단일 요청에 대해 추론을 끄려면 enable_thinking을 전달합니다. 이 경우 응답에는 추론 내용이 포함되지 않으므로, message.content만 읽을 수 있습니다.

# Disable thinking for a single request
response = client.chat.completions.create(
    model="furiosa-ai/Qwen3-30B-A3B-FP8",
    messages=[{"role": "user", "content": "What is the capital of France?"}],
    extra_body={"chat_template_kwargs": {"enable_thinking": False}},
)
print(response.choices[0].message.content)

모든 요청을 기본적으로 추론 기능을 끄도록 설정하려면, 서버를 --default-chat-template-kwargs 옵션으로 시작합니다 (하지만 개별 요청은 자체 chat_template_kwargs를 사용하여 추론 기능을 다시 활성화할 수 있습니다).

furiosa-llm serve furiosa-ai/Qwen3-30B-A3B-FP8 \
  --reasoning-parser qwen3 \
  --default-chat-template-kwargs '{"enable_thinking": false}'

다른 변형은 enable_thinking를 읽지 않습니다. Instruct 및 Coder 변형은 추론을 수행하지 않으며, Qwen3-30B-A3B-Thinking-2507-FP8는 항상 추론을 수행합니다. 따라서 스위치는 이 변형에는 영향을 미치지 않습니다.

도구 호출. 서버를 [구체적인 정보 삽입]을 사용하여 시작할 때 --enable-auto-tool-choice --tool-call-parser hermes ( 참조) 서버를 시작하세요), 통과 tools 요청에서 모델을 결정할 때 호출합니다. 참조 도구 호출 가이드 tool-choice 옵션에 대한 완벽한 클라이언트 예 및 세부 사항.
