Qwen3-Reranker#

The Qwen3-Reranker 시리즈는 Qwen3 조밀한 변압기 백본에 건설된 reranking 모형의 가족입니다. 조회를 주고 후보자 문서의 세트를 주기 위하여, 그들은 재주문 검색 결과에 사용된 relevance 점수를 생성합니다 — retrieval-augmented 세대 (RAG)에 있는 일반적인 두번째 단계 및 수선.

FuriosaAI는 Qwen3-Reranker 모형을 아래에 발행합니다 furiosa-ai 구성 요소가 Hugging Face 허브에 연결됨, 각 발송 Furiosa 실행 가능한 번들 (FXB)에 그것을 달리기를 위해 FuriosaAI RNGD Furiosa-LLM로. 동일한 상류 무게는 또한 다른 기구 (지속 변압기와 같은 vLLM 및 변압기); 그와 함께 사용을 위해, 아래에 연결되는 상류 모형 카드를 보십시오.

관련 임베딩 모델은 다음을 참조하십시오: Qwen3-Embedding; dense Qwen3 채팅 모델 참조 Qwen3 (밀집).

사용#

Furiosa-LLM와 함께 이러한 모델을 실행하려면 아래 예제를 따르십시오. Furiosa-LLM 및 그 전제 조건 설치. 모델을 온라인 서버(OpenAI 호환)를 통해 또는 Furiosa-LLM Python API를 통해 오프라인으로 사용할 수 있습니다. 아래의 변형 탭을 선택하면, 이 페이지의 모든 예제에서 선택이 동기화됩니다.

서버를 시작하세요#

모델을 지정하여 제공: furiosa-ai/<repo> 식별자:

# Launch the server, listening on port 8000 by default
furiosa-llm serve furiosa-ai/Qwen3-Reranker-0.6B

# Launch the server, listening on port 8000 by default
furiosa-llm serve furiosa-ai/Qwen3-Reranker-4B

# Launch the server, listening on port 8000 by default
furiosa-llm serve furiosa-ai/Qwen3-Reranker-8B

서버가 준비되면 다음을 볼 수 있습니다.

기본 사용#

서버는 /v1/rerank endpoint (Cohere/Jina rerank API와 호환, 또한 vLLM에 의해 사용). 쿼리 및 후보 문서를 보내 curl; 서버는 재주문을 받아서 문서를 반환합니다 relevance_score:

curl http://localhost:8000/v1/rerank \
    -H "Content-Type: application/json" \
    -d '{
    "model": "furiosa-ai/Qwen3-Reranker-0.6B",
    "query": "What is deep learning?",
    "documents": [
        "Deep learning is a subset of machine learning using neural networks.",
        "Python is a popular programming language for data science.",
        "Neural networks are inspired by biological neural networks."
    ]
    }' \
    | python -m json.tool

Python와 동일 할 수 있습니다. requests 도서관, 그리고 통과 top_n 가장 관련 문서만 보관하려면:

import requests

response = requests.post(
    "http://localhost:8000/v1/rerank",
    json={
        "model": "furiosa-ai/Qwen3-Reranker-0.6B",
        "query": "What is deep learning?",
        "documents": [
            "Deep learning is a subset of machine learning using neural networks.",
            "Python is a popular programming language for data science.",
            "Neural networks are inspired by biological neural networks.",
        ],
        "top_n": 2,
    },
)

for result in response.json()["results"]:
    print(f"score={result['relevance_score']:.4f}  {result['document']['text']}")

발전 된 사용#

오프라인 사용을 위해, 모형을 가진 적재하십시오 LLM constructor (Repo에서 발송되는 FXB는 자동적으로 발견됩니다)와 호출 score 쿼리 및 후보 문서로 relevance 점수를 얻는:

from furiosa_llm import LLM

with LLM("furiosa-ai/Qwen3-Reranker-0.6B") as llm:
    query = "What is deep learning?"
    documents = [
        "Deep learning is a subset of machine learning using neural networks.",
        "Python is a popular programming language for data science.",
    ]
    outputs = llm.score(query, documents)
    for document, output in zip(documents, outputs):
        print(f"score={output.outputs.score:.4f}  {document}")
