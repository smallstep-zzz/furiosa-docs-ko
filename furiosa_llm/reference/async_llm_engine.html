AsyncLLMEngine 클래스#

개요#

AsyncLLMEngine는 비동기 인터페이스를 제공하여 텍스트 생성을 지원하며, 명령줄 인수를 통해 구성할 수 있습니다.

사용 예시#

import argparse
from furiosa_llm import AsyncLLMEngine, AsyncEngineArgs, SamplingParams

async def main():
    parser = argparse.ArgumentParser()
    parser = AsyncEngineArgs.add_cli_args(parser)
    args = parser.parse_args()
    engine_args = AsyncEngineArgs.from_cli_args(args)
    engine = AsyncLLMEngine.from_engine_args(engine_args)
    example_input = {
        "prompt": "What is LLM?",
        "temperature": 0.0,
        "request_id": "request-123",
    }

    results_generator = engine.generate(
        example_input["prompt"],
        SamplingParams(temperature=example_input["temperature"]),
        example_input["request_id"]
    )

    final_output = None
    async for request_output in results_generator:
        final_output = request_output

    print(final_output)

if __name__ == "__main__":
    import asyncio
    asyncio.run(main())

스크립트는 AsyncEngineArgs에 정의된 다양한 인수를 사용하여 실행할 수 있습니다. 다음 예시를 참조하십시오.

python engine_cli_async.py --model /path/to/model --devices npu:0

AsyncEngineArgs에 사용 가능한 모든 인수에 대한 자세한 내용은 아래 섹션을 참조하십시오.

API 참조#

class furiosa_llm.AsyncLLMEngine(native_engine: NativeEngineLike, tokenizer: PythonBackend | TokenizersBackend, task_type: Literal['generate', 'embed', 'classify', 'score', 'token_embed', 'token_classify', 'plugin'], max_model_len: int, llm: LLM | None = None, model_path: str | None = None, trust_remote_code: bool = False)[source]#

AsyncLLMEngine은 요청을 받아 비동기적으로 텍스트를 생성합니다. vLLM의 AsyncLLMEngine과 호환되는 API 인터페이스를 구현하지만, 이 클래스는 furiosa-runtime 및 FuriosaAI NPU를 기반으로 합니다.

async abort(request_id: str) → None[source]#

주어진 ID를 사용하여 요청을 취소합니다.

async encode(prompt: str | TextPrompt | TokensPrompt, pooling_params: PoolingParams, request_id: str, lora_request=None, trace_headers=None, priority=None, truncate_prompt_tokens: int | None = None, tokenization_kwargs: dict[str, Any] | None = None) → AsyncGenerator[PoolingRequestOutput, None][source]#

입력 프롬프트에 해당하는 hidden states에 pooling을 적용합니다.

lora_request, trace_headers, truncate_prompt_tokens, 및 priority는 지원되지 않습니다. 이는 vLLM API와의 호환성을 위한 자리 표시자일 뿐입니다.

classmethod from_engine_args(args: AsyncEngineArgs) → AsyncLLMEngine[source]#

AsyncLLMEngine를 AsyncEngineArgs에서 생성합니다.

async generate(prompt: str | TextPrompt | TokensPrompt, sampling_params: SamplingParams, request_id: str) → AsyncGenerator[RequestOutput, None][source]#

주어진 프롬프트에 대한 텍스트 완료를 생성합니다.

원시 비전 토큰 수 불일치는 멀티모달 요청이 중단된 후 반복 중에 MultimodalTokenCountError를 발생시킵니다.

매개변수:

  • prompt – LLM에 전달할 프롬프트. 각 입력의 형식을 참조하기 위해 PromptType을 참조하십시오.

  • sampling_params – 요청에 적용할 샘플링 설정입니다.

  • request_id – 요청의 고유 ID입니다.
