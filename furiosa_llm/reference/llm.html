주어진 프롬프트와 샘플링 파라미터를 사용하여 텍스트를 생성하는 LLM.

chat(messages: list[ChatCompletionMessageParam] | list[list[ChatCompletionMessageParam]], sampling_params: SamplingParams | None = None, chat_template: str | None = None, chat_template_content_format: Literal['string'] = 'string', add_generation_prompt: bool = True, continue_final_message: bool = False, tools: list[dict[str, Any]] | None = None, chat_template_kwargs: dict[str, Any] | None = None) → list[RequestOutput][source]#

챗 대화에 대한 응답을 생성합니다.

토크나이저로 대화를 텍스트 프롬프트로 변환한 뒤 generate()를 호출해 응답을 생성합니다.

매개변수:

  • 메시지 –

    대화 목록 또는 단일 대화.

    • 각 대화는 메시지 목록으로 표현됩니다.

    • 각 메시지는 'role' (역할) 및 'content' (내용) 키를 가진 딕셔너리입니다.

  • sampling_params – 텍스트 생성에 사용되는 샘플링 파라미터.

  • chat_template – 챗 대화의 구조를 정의하는 템플릿. 제공되지 않으면 모델의 기본 챗 템플릿이 사용됩니다.

  • chat_template_content_format – 메시지 콘텐츠를 렌더링하는 형식 (현재 "string"만 지원).

  • add_generation_prompt – True로 설정하면 각 메시지에 생성 템플릿을 추가합니다.

  • continue_final_message – True이면 새 메시지를 시작하는 대신 대화의 마지막 메시지에 이어서 생성합니다. add_generation_prompt와 동시에 True로 설정할 수 없습니다.

  • tools – 채팅에서 사용할 수 있는 선택적 도구 목록.

  • chat_template_kwargs – 채팅 템플릿 렌더링 함수에 전달할 추가 키워드 인자.

반환값:

생성된 응답을 입력 메시지와 같은 순서로 담은 RequestOutput 객체 목록입니다.

  • pooling_params – 풀링에 사용될 풀링 매개변수.

반환값:

입력 프롬프트의 순서와 동일한 방식으로 임베딩 벡터를 포함하는 EmbeddingRequestOutput 객체의 목록.

encode(prompts: str | TextPrompt | TokensPrompt | Sequence[str | TextPrompt | TokensPrompt], pooling_params: PoolingParams | Sequence[PoolingParams] | None = None, *, pooling_task: Literal['embed', 'classify', 'score', 'token_embed', 'token_classify', 'plugin'] | None = None) → list[PoolingRequestOutput][source]#

generate(prompts: str | list[str], sampling_params: SamplingParams | None = None, prompt_token_ids: BatchEncoding | None = None, tokenizer_kwargs: dict[str, Any] | None = None) → RequestOutput | list[RequestOutput][source]#

주어진 프롬프트와 샘플링 매개변수를 사용하여 텍스트를 생성합니다.

매개변수:

  • prompt_token_ids – 미리 토큰화한 프롬프트를 담은 BatchEncoding 객체입니다. 생략하면 내부에서 토크나이저로 프롬프트를 토큰화합니다.

  • tokenizer_kwargs – 토크나이저의 encode 메서드에 추가로 전달할 키워드 인자입니다. 예를 들어 {"use_special_tokens": True}를 전달할 수 있습니다.

생성 결과를 입력 프롬프트와 같은 순서로 담은 RequestOutput 객체 목록입니다.

get_default_sampling_params() → SamplingParams[source]#

모델의 generation_config 기본값을 반영하는 SamplingParams 객체를 반환합니다.

모델에 generation_config가 없거나 HF 기본값과 일치하는 경우, 기본 SamplingParams() 객체를 반환합니다.

score(data_1: str | TextPrompt | TokensPrompt | Sequence[str | TextPrompt | TokensPrompt], data_2: str | TextPrompt | TokensPrompt | Sequence[str | TextPrompt | TokensPrompt], /, *, truncate_prompt_tokens: int | None = None, pooling_params: PoolingParams | None = None, chat_template: str | None = None) → list[ScoringRequestOutput][source]#

모든 <text,text_pair> 쌍의 유사도 점수를 계산합니다.

입력은 1 -> 1, 1 -> N 또는 N -> N 형태일 수 있습니다. 1 - N의 경우, data_1 입력은 data_2 입력과 쌍을 이루기 위해 N번 복제됩니다.

매개변수:

  • data_1 – 단일 프롬프트 또는 프롬프트 목록일 수 있습니다. 목록인 경우, 길이는 data_2 목록과 동일해야 합니다.

  • data_2 – LLM에 대한 입력으로 구성하기 위한 쿼리와 함께 사용할 데이터입니다.

  • truncate_prompt_tokens – 프롬프트를 자르는 토큰 수를 지정합니다.

  • pooling_params – 풀링에 사용할 풀링 매개변수입니다. None인 경우, 기본 풀링 매개변수가 사용됩니다.

  • chat_template – 점수를 계산하는 데 사용할 챗 템플릿입니다. None인 경우, 모델 자체의 형식이 사용됩니다. 이 템플릿은 vLLM의 템플릿 계약에 따라 정확히 두 개의 메시지(쿼리 및 문서)를 받습니다.

반환값:

점수가 생성된 ScoringRequestOutput 객체의 목록으로, 입력 프롬프트와 동일한 순서로 구성됩니다.

주요 메서드#

generate()#

주어진 프롬프트에 대한 샘플링 매개변수를 사용하여 텍스트 완성(completion)을 생성합니다. 텍스트 생성 작업의 주요 방법입니다.

언제 sampling_params 방치되거나 None, get_default_sampling_params() 사용됩니다. 동일한 동작은 적용됩니다. furiosa_llm.LLM.chat() and furiosa_llm.LLM.stream_generate()보시다시피 generation_config.json의 기본 Sampling 매개 변수 세부사항을 알려주세요.

사용 예시는 채팅 예제를 참조하십시오.

구성된 중단 문자열에 의해 중단된 완료(completion)의 경우, 단일 프롬프트에 대해 result.outputs[j].stop_reason 또는 배치 프롬프트에 대해 results[i].outputs[j].stop_reason을 확인하십시오. 이는 일치하는 중단 문자열이거나, 생성이 다른 이유로 종료된 경우 None입니다. finish_reason은 생성 종료 이유를 설명합니다.

get_default_sampling_params()#

generate(), chat(), 또는 stream_generate()를 호출할 때 명시적인 sampling_params 인수가 제공되지 않은 경우에 사용되는 furiosa_llm.SamplingParams 객체를 반환합니다.

모델 저장소 또는 로컬 디렉토리가 포함 된 경우 generation_config.json 파일, 그 값은 반환된 객체를 대체합니다. 그렇지 않으면 일반 SamplingParams() 다시 돌려받았어요 generation_config.json의 기본 Sampling 매개 변수 명예 필드의 전체 목록 및 서버 측의 해상도 규칙.

embed()#

주어진 프롬프트에 대한 임베딩 벡터를 생성합니다. 이 메서드는 임베딩 모델에만 적용됩니다.

매개변수:

  • prompts (PromptType | 프롬프트 유형의 시퀀스): 인코딩할 프롬프트입니다. 단일 프롬프트 또는 배치 처리를 위한 프롬프트 시퀀스일 수 있습니다.

  • pooling_params (PoolingParams | 프롬프트 유형의 시퀀스 | None): 풀링 매개변수입니다. None인 경우 기본 매개변수가 사용됩니다.

반환값:

  • List[EmbeddingRequestOutput]: 입력 프롬프트와 동일한 순서로 임베딩 벡터를 포함하는 임베딩 결과 목록.

예시:

from furiosa_llm import LLM, PoolingParams

with LLM("furiosa-ai/Qwen3-Embedding-0.6B") as llm:
    # Single embedding
    outputs = llm.embed("Hello, world!")
    embedding = outputs[0].outputs.embedding

    # Batch embedding with normalization disabled
    params = PoolingParams(normalize=False)
    outputs = llm.embed(["First text", "Second text"], pooling_params=params)

score()#

텍스트 쌍에 대한 유사도 점수를 생성합니다. 이 메서드는 Qwen3-Reranker 모델 또는 as_binary_seq_cls_model을 사용하여 변환된 모델을 포함한 이진 분류 모델에만 적용됩니다.

매개변수:

  • data_1 (PromptType | Sequence[PromptType]): 첫 번째 입력 텍스트(들). 단일 프롬프트 또는 목록일 수 있습니다.

  • data_2 (PromptType | 프롬프트 유형 목록): 첫 번째 프롬프트와 쌍을 이루는 두 번째 입력 텍스트(들).

  • truncate_prompt_tokens (정수 | None): 프롬프트를 자르는 최대 토큰 수를 지정합니다. None인 경우 자르기가 수행되지 않습니다.

  • pooling_params (PoolingParams | None): 풀링 매개변수. None인 경우 기본 매개변수가 사용됩니다.

  • chat_template (문자열 | None): 점수를 위한 사용자 지정 챗 템플릿. None인 경우 모델의 기본 템플릿이 사용됩니다.

입력 패턴:

  • 1-to-1: 단일 텍스트와 단일 텍스트를 쌍으로 연결합니다.

  • 1-대-N: 단일 텍스트와 여러 텍스트의 쌍 (data_1이 N번 복제됨)

  • N-대-N: 텍스트 목록을 요소별로 쌍으로 연결 (두 목록 모두 길이가 동일해야 함)

반환값:

  • List[ScoringRequestOutput]: 입력 쌍과 동일한 순서로 유사도 점수를 포함하는 점수 결과 목록.

예시:

from furiosa_llm import LLM, PoolingParams

with LLM("furiosa-ai/Qwen3-Reranker-0.6B") as llm:
    # 1-to-N scoring: one query against multiple documents
    query = "What is machine learning?"
    documents = [
        "Machine learning is a subset of AI",
        "Python is a programming language",
        "Deep learning uses neural networks"
    ]

    outputs = llm.score(query, documents)
    for i, output in enumerate(outputs):
        print(f"Document {i}: score = {output.outputs.score}")

자세한 내용은 점수 예제를 참조하세요.
