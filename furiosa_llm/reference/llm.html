주어진 프롬프트 및 sampling 매개 변수에서 텍스트를 생성하기위한 LLM.

chat(messages: list[ChatCompletionMessageParam] | list[list[ChatCompletionMessageParam]], sampling_params: SamplingParams | None = None, chat_template: str | None = None, chat_template_content_format: Literal['string'] = 'string', add_generation_prompt: bool = True, continue_final_message: bool = False, tools: list[dict[str, Any]] | None = None, chat_template_kwargs: dict[str, Any] | None = None) → list[RequestOutput][source]#

채팅 대화에 대한 응답 생성.

채팅 대화는 Tokenizer를 사용하여 텍스트 prompt로 변환되며 통화 generate() 응답을 생성하는 방법.

매개 변수:

  • 메시지 –

    대화 또는 단일 대화의 목록.

    • 각 대화는 메시지 목록으로 표시됩니다.

    • 각 메시지는 'role'과 'content'키로 사전입니다.

  • sampling_params – 텍스트 생성에 대한 sampling 매개 변수.

  • chat_template - 채팅을 파괴하는 템플릿. 제공되지 않은 경우, 모델의 기본 채팅 템플릿이 사용됩니다.

  • chat_template_content_format – 메시지 콘텐츠를 렌더링하는 형식. 현재 “string”만 지원됩니다.

  • add_generation_prompt – True가 있다면, 생성 템플릿을 각 메시지에 추가합니다.

  • continue_final_message – True가 있다면, 새로운 것을 시작하는 대신 대화에서 최종 메시지가 계속됩니다. Cannot이 될 수 없습니다 True if add_generation_prompt 또한 True.

  • 도구 – 채팅에서 사용할 수있는 도구의 선택 목록.

  • chat_template_kwargs - 채팅 템플릿 렌더링 기능에 전달하는 추가 키워드 인수.

반환값:

이 목록은 RequestOutput 입력 메시지와 동일한 순서에 있는 생성한 응답을 포함하는 목표.

embed(prompts: str | TextPrompt | TokensPrompt | Sequence[str | TextPrompt | TokensPrompt], pooling_params: PoolingParams | Sequence[PoolingParams] | None = None) → list[EmbeddingRequestOutput][source]#

– embedding, prompt당 반환할 로그 확률의 개수. embedding (기본값)로 설정하면 ZXQ3ZXQ 로그 확률이 반환되지 않습니다. 음수 정수 (0 이상)로 설정하면 각 ZXQ4ZXQ, ZXQ5ZXQ 위치에 대한 상위 k개의 로그 확률과 실제 ZXQ6ZXQ의 로그 확률을 반환합니다. 모든 어휘 토큰에 대한 로그 확률을 반환하려면 -1로 설정합니다.

매개 변수:

  • prompts – LLM에 대한 프롬프트. 일괄 embedding에 대한 프롬프트의 시퀀스를 전달할 수 있습니다.

  • pooling_params – 풀링 매개 변수.

반환값:

이 목록은 EmbeddingRequestOutput 입력 프롬프트와 같은 순서에 embedding 벡터를 포함하는 개체.

score(data_1: str | TextPrompt | TokensPrompt | Sequence[str | TextPrompt | TokensPrompt], data_2: str | TextPrompt | TokensPrompt | Sequence[str | TextPrompt | TokensPrompt], /, *, truncate_prompt_tokens: int | None = None, pooling_params: PoolingParams | None = None, chat_template: str | None = None) → list[ScoringRequestOutput][source]#

모든 쌍에 대한 유사성 점수 생성 <텍스트,text_pair>.

입력값은 1 -> 1, 1 -> N or N -> N. 1 - N 이 사건 data_1 입력은 복제됩니다. N 번의 횟수로 data_2 입력값

매개 변수:

  • data_1 - 단일 prompt 또는 프롬프트의 목록이 될 수 있습니다. 목록이되면 동일한 길이를해야합니다. data_2 목록.

  • data_2 – LLM에 입력을 입력하도록 쿼리를 결합하는 데이터.

  • truncate_prompt_tokens – prompt를 truncate에 토큰의 수.

  • pooling_params – 풀링을위한 풀링 매개 변수. None인 경우, 우리는 기본 풀링 매개 변수를 사용합니다.

  • chat_template – scoring에 사용할 채팅 템플릿. None가 있다면, 모델의 자체 형식이 사용됩니다. 템플릿은 정확히 두 개의 메시지를 수신, 질문 and 문서vLLM의 템플릿 계약과 일치합니다.

반환값:

이 목록은 점수 요청 출력 입력 프롬프트와 같은 순서에 있는 생성된 점수를 포함하는 목표.

주요 방법#

생성함)#

샘플링 설정을 사용해 주어진 프롬프트의 이어지는 텍스트를 생성합니다. 텍스트 생성에 사용하는 기본 메서드입니다.

언제 sampling_params 방치되거나 None, get_default_sampling_params() 사용됩니다. 동일한 동작은 적용됩니다. furiosa_llm.LLM.chat() and furiosa_llm.LLM.stream_generate()보시다시피 generation_config.json의 기본 Sampling 매개 변수 세부사항을 알려주세요.

보시다시피 채팅 예제 사용용으로

설정된 정지 문자열에 의해 완료된 경우, 검사 result.outputs[j].stop_reason : 단일 prompt 또는 results[i].outputs[j].stop_reason 일괄 처리 된 프롬프트에 대 한. 그것은 일치된 정지 문자열, 또는 None 다른 이유를 위해 끝낼 때; finish_reason 계속되는 이유 생성을 설명합니다.

get_default_sampling_params()#

반환 furiosa_llm.SamplingParams 사용할 때 generate(), chat(), or stream_generate() 명시적인 호출 없이 sampling_params 논쟁.

모델 저장소 또는 로컬 디렉토리가 포함 된 경우 generation_config.json 파일, 그 값은 반환된 객체를 대체합니다. 그렇지 않으면 일반 SamplingParams() 다시 돌려받았어요 generation_config.json의 기본 Sampling 매개 변수 명예 필드의 전체 목록 및 서버 측의 해상도 규칙.

임베드 ( ⁇ )#

주어진 프롬프트에 대한 embedding 벡터 생성. 이 방법은 embedding 모델에만 적용됩니다.

매개 변수:

  • prompts (PromptType | Sequence[PromptType]): 인코딩에 대한 프롬프트입니다. 일괄 처리에 대한 단일 prompt 또는 스퀀스가 될 수 있습니다.

  • pooling_params (PoolingParams | Sequence[PoolingParams] | None): 풀링 매개 변수. None인 경우, 기본 매개 변수가 사용됩니다.

반환값:

  • List[EmbeddingRequestOutput]: embedding 출력의 목록은 입력 프롬프트와 같은 순서에 embedding 벡터를 포함.

예를 들어:

from furiosa_llm import LLM, PoolingParams

with LLM("furiosa-ai/Qwen3-Embedding-0.6B") as llm:
    # Single embedding
    outputs = llm.embed("Hello, world!")
    embedding = outputs[0].outputs.embedding

    # Batch embedding with normalization disabled
    params = PoolingParams(normalize=False)
    outputs = llm.embed(["First text", "Second text"], pooling_params=params)

점수)#

텍스트 쌍에 대한 유사성 점수를 생성. 이 방법은 Qwen3-Reranker 모델 또는 모델을 사용하여 변환을 포함하여 바이너리 분류 모델에만 지원됩니다 as_binary_seq_cls_model.

매개 변수:

  • data_1 (PromptType | Sequence[PromptType]): 첫 번째 입력 텍스트(s). 단일 prompt 또는 목록이 될 수 있습니다.

  • data_2 (PromptType | Sequence[PromptType])는 data_1의 각 입력과 짝지을 두 번째 텍스트입니다.

  • truncate_prompt_tokens (int | None): prompt를 truncate 토큰의 최대 수. None인 경우, truncation이 적용되지 않습니다.

  • pooling_params (PoolingParams | None): 풀링 매개 변수. None의 기본 매개 변수가 사용됩니다.

  • chat_template (str | None): scoring에 대한 사용자 정의 채팅 템플릿. None가 있다면, 모델의 기본 템플릿이 사용됩니다.

입력 패턴:

  • 1-to-1: 단일 텍스트 쌍 단일 텍스트

  • 1-to-N: 여러 텍스트로 구성된 단일 텍스트 (data_1는 N 시간을 복제합니다)

  • N-to-N: 다중 텍스트 쌍 element-wise (일부 목록은 동일한 길이가 있어야 함)

반환값:

  • List[ScoringRequestOutput]: 입력쌍과 같은 순서에 있는 유사점 점수를 포함하는 산출의 명부.

예를 들어:

from furiosa_llm import LLM, PoolingParams

with LLM("furiosa-ai/Qwen3-Reranker-0.6B") as llm:
    # 1-to-N scoring: one query against multiple documents
    query = "What is machine learning?"
    documents = [
        "Machine learning is a subset of AI",
        "Python is a programming language",
        "Deep learning uses neural networks"
    ]

    outputs = llm.score(query, documents)
    for i, output in enumerate(outputs):
        print(f"Document {i}: score = {output.outputs.score}")
