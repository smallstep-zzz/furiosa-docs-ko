PoolingParams 클래스#

class furiosa_llm.PoolingParams(truncate_prompt_tokens: int | None = None, dimensions: int | None = None, normalize: bool | None = True, task: Literal['embed', 'classify', 'score', 'token_embed', 'token_classify', 'plugin'] | None = None)[source]#

기반 클래스: object

풀링 모델에 대한 API 매개변수.

truncate_prompt_tokens#

프롬프트 자르기를 제어합니다. -1로 설정하면 모델의 기본 자르기 크기를 사용합니다. k로 설정하면 마지막 k개의 토큰만 유지합니다 (왼쪽 자르기). None으로 설정하면 자르기를 비활성화합니다.

dimensions#

출력 임베딩의 차원 수입니다. 설정하면 임베딩을 처음 N개의 차원으로 자릅니다 (Matryoshka 표현 학습). 양의 정수여야 합니다.

normalize#

임베딩 결과의 정규화를 수행할지 여부. (정규화, normalization) 단, 임베딩 작업에만 적용 가능합니다.

매개변수#

작업#

유형: PoolingTask (문자열: "embed", "score")

풀링 작업 유형을 지정합니다:

  • "embed": 임베딩 생성 작업에 사용됩니다. 모델은 밀집 벡터 표현을 출력합니다.

  • "score": 유사도 평가 작업에 사용됩니다. 모델은 스칼라 유사도 점수를 출력합니다.

이 매개변수는 일반적으로 모델의 메타데이터에서 유추되지만, 필요에 따라 명시적으로 설정할 수 있습니다. (메타데이터)

normalize#

유형: bool

기본값: True

L2 정규화를 사용하여 임베딩 출력을 정규화할지 여부를 지정합니다. (정규화) 이 옵션은 임베딩 작업(task="embed")에만 적용됩니다.

True로 설정하면 임베딩 벡터가 단위 길이로 정규화되므로, 다음 작업에 유용합니다:

  • 코사인 유사도 계산

  • 벡터 크기 차이의 영향을 줄임

  • 다운스트림 작업에 대한 임베딩 정규화

예시:

from furiosa_llm import LLM, PoolingParams

with LLM("furiosa-ai/Qwen3-Embedding-0.6B") as llm:
    # With normalization (default)
    params_normalized = PoolingParams(normalize=True)
    outputs = llm.embed("Hello, world!", pooling_params=params_normalized)
    # Output vectors have unit length (L2 norm = 1.0)

    # Without normalization
    params_raw = PoolingParams(normalize=False)
    outputs = llm.embed("Hello, world!", pooling_params=params_raw)
    # Output vectors preserve original magnitudes

truncate_prompt_tokens#

유형: int | None

기본값: None

입력 프롬프트를 최대 몇 토큰으로 자르는지 지정하는 값입니다. 입력이 이 제한을 초과하면, 해당 제한 내로 잘립니다.

None으로 설정하면, 자르기가 수행되지 않고, 입력은 모델의 최대 시퀀스 길이에 맞춰 처리됩니다.

특히 다음과 같은 경우에 유용합니다:

  • 배치 처리에서 길이가 변하는 입력을 처리하는 경우

  • 모델의 제약 조건 내에 입력을 맞추는 경우

  • 긴 문서에 대한 계산 비용 제어

예시:

from furiosa_llm import PoolingParams

# Truncate to 512 tokens
params = PoolingParams(truncate_prompt_tokens=512)

차원 (dimensions)#

유형: int | None

기본값: None

임베딩 출력의 차원을 지정된 개수의 차원으로 줄입니다.

None인 경우, 모델에서 제공하는 전체 임베딩 차원이 반환됩니다.

이 매개변수는 다음과 같은 용도로 유용합니다:

  • 저장 공간 요구 사항 감소

  • 후방 유사성 계산 속도 향상

  • 다른 시스템과의 호환성을 위한 임베딩 차원 매칭

참고: 모든 모델이 차원 축소 기능을 지원하지 않습니다. 이 매개변수를 사용하기 전에 모델의 기능을 확인하십시오.

예시:

from furiosa_llm import PoolingParams

# Reduce to 256 dimensions
params = PoolingParams(dimensions=256)
