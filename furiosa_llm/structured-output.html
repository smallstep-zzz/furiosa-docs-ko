구조화된 출력#

Furiosa-LLM는 구조화된 산출 발생을 지원하고, 특정한 체재, 스키마, 또는 본을 따르기 위하여 모형의 산출을 constrain 가능하게 합니다. 이 특징은 JSON 자료 적출과 같은 일관된, parsable 응답을 요구하는 신청을 위해 근본적입니다. any-formatted 텍스트 생성.

구조화된 출력에 대한 백엔드#

Furiosa-LLM는 구조화된 산출을 위한 다수 백엔드를 지원합니다:

  • xgrammar (과태): High-performance grammar-guided 세대를 사용하여 X그램머

  • 안내: 효율적인 제약 시행 안내

성능과 호환성 요구 사항에 따라 백엔드를 선택할 수 있습니다.

서빙 명령을 사용하여:

furiosa-llm serve <model> --structured-outputs-backend {auto,guidance,xgrammar}

Python를 사용하여 API를 활용:

from furiosa_llm import LLM

with LLM(
    model_id_or_path,
    structured_outputs_backend="guidance",  # or "xgrammar", "auto"
) as llm:
    outputs = llm.generate(prompts, sampling_params)

이 옵션은 구조화 된 출력에 사용하도록 구조화 된 출력 백엔드를 결정합니다.

사용 가능한 옵션은 다음과 같습니다:

  • auto (과태): 엔진은 backend를 선택합니다. 그것은 현재 xgrammar에 과태합니다.

  • guidance: Explicitly는 llguidance 백엔드를 선택합니다.

  • xgrammar: Explicitly는 XGrammar 백엔드를 선택합니다.

이 선택은 각 사용자 요청에 대해 overridden 할 수 있습니다. 아래 설명.

동적 백엔드 선택#

Furiosa-LLM는 역동적인, backend의 per-request 선택을 지원합니다. 사용자는 분야를 사용할 수 있습니다 backend 이 요청에서 사용할 백엔드를 지정합니다.

이 필드가 복부되거나 설정된 경우 auto, 서버의 기본 백엔드 (위에 설명된 대로 chosen) 사용 됩니다.

response = client.chat.completions.create(
   model="my-model",
   messages=[{"role": "user", "content": "Classify: positive or negative"}],
   extra_body={
      "structured_outputs": {
         "backend": "xgrammar", # or "guidance", "auto"
         "choice": ["positive", "negative"],
      }
   },
)

OpenAI 및 API를 통해 지원되는 방법#

사용자는 OpenAI의 둘 다를 사용하여 구조화된 산출을 생성할 수 있습니다 완료 API and 채팅 완료 API. Furiosa-LLM는 구조상 산출 constraints의 4개의 주요 유형을 지원합니다:

  • 선택: 출력을 강제로 predefined 옵션 중 하나

  • 정규 표현식: 특정 정규 표현식 패턴 일치 텍스트 생성

  • JSON Schema: 미리 정의된 schema를 따르는 JSON 산출을 일으키십시오

  • Context-free Grammar : context-free 문법 사양에 따라 텍스트 생성

선택#

The choice 필드 structured_outputs 모델 출력은 선택의 사전 정의 세트 중 하나가 될 수 있습니다. 이것은 특정 옵션에서 선택할 모델이 필요한 경우 분류 작업에 특히 유용합니다.

사용 예제:

import os
from openai import OpenAI

base_url = os.getenv("OPENAI_BASE_URL", "http://localhost:8000/v1")
api_key = os.getenv("OPENAI_API_KEY", "EMPTY")
client = OpenAI(api_key=api_key, base_url=base_url)

# Sample review to classify
review = "This movie was absolutely fantastic!"

response = client.chat.completions.create(
    model=client.models.list().data[0].id,
    messages=[{"role": "user", "content": f"Classify sentiment: '{review}'"}],
    extra_body={
        "structured_outputs": {"choice": ["positive", "negative", "neutral"]},
    },
    temperature=0.0,
)

content = response.choices[0].message.content
assert content and content.strip() in {"positive", "negative", "neutral"}, content  # validate the result
print(content)

사용 사례:

  • 감정 분석

  • 카테고리 분류

  • 객관식 질문

  • 바이너리 결정 (yes/no, true/false)

정기적 인 표현#

The regex 필드 structured_outputs 생성된 텍스트는 특정 정규 표현식 패턴과 일치합니다. 이것은 이메일 주소, 전화 번호, 또는 사용자 정의 형식과 같은 구조 텍스트를 생성하는 데 유용합니다.

사용 예제:

import os
import re
from openai import OpenAI

base_url = os.getenv("OPENAI_BASE_URL", "http://localhost:8000/v1")
api_key = os.getenv("OPENAI_API_KEY", "EMPTY")
client = OpenAI(api_key=api_key, base_url=base_url)

# Email address pattern
email_pattern = r"[a-z0-9.]{1,20}@\w{6,10}\.com\n"

response = client.chat.completions.create(
    model=client.models.list().data[0].id,
    messages=[{"role": "user", "content": "Generate an email address for Ada Lovelace, who works in Analytical. End in .com and new line. Example result: 'ada.lovelace@analytical.com\n'"}],
    extra_body={
        "structured_outputs": {"regex": email_pattern},
    },
    temperature=0.0,
)

content = response.choices[0].message.content
assert content and re.fullmatch(email_pattern, content), content  # validate the result
print(content)

사용 사례:

  • 이메일 주소 생성

  • 전화 번호 형식 설정

  • ID 또는 코드 생성

  • 사용자 정의 텍스트 패턴

  • URL 또는 파일 경로 생성

JSON 계획#

The json 필드 structured_outputs 가장 일반적으로 사용되는 구조화 된 출력 방법입니다. 생성 된 출력은 지정된 스키마에 따라 JSON 유효합니다. 이것은 구조화 된 데이터를 추출하거나 일관된 API 응답을 만드는 데 이상적입니다.

사용 예제:

import enum
import json
import os
from openai import OpenAI
import pydantic

base_url = os.getenv("OPENAI_BASE_URL", "http://localhost:8000/v1")
api_key = os.getenv("OPENAI_API_KEY", "EMPTY")
client = OpenAI(api_key=api_key, base_url=base_url)

class Color(str, enum.Enum):
    BLUE = "blue"
    GREEN = "green"
    PURPLE = "purple"

class FruitDescription(pydantic.BaseModel):
    name: str
    color: Color
    taste: str

response = client.chat.completions.create(
    model=client.models.list().data[0].id,
    messages=[{"role": "user", "content": "Generate a JSON with the name, color, and taste of your favorite fruit."}],
    response_format={
        "type": "json_schema",
        "json_schema": {
            "name": "fruit-description",
            "schema": FruitDescription.model_json_schema(),
        },
    },
    temperature=0.0,
)

content = response.choices[0].message.content
assert content, "expected non-empty content"
result = json.loads(content)
FruitDescription.model_validate(result)  # validate the result against the schema
print(json.dumps(result, indent=2))

사용 사례:

  • unstructured 텍스트에서 데이터 추출

  • API 응답 형식 지정

  • 데이터베이스 레코드 생성

  • 구성 파일 생성

Context-free 문법#

The grammar 필드 structured_outputs 생성된 텍스트가 따라야 하는 context-free 문법 사양을 정의할 수 있습니다. 이것은 출력 구조에 가장 유연한 컨트롤을 제공합니다.

문법 형식 지원:

llguidance backend는 현재 여러 가지 문법 형식을 지원합니다:

  • EBNF (Extended Backus-Naur Form)표준 문법 표기법을 사용 ::= 문법

  • 래크: Python의 현대 패싱 라이브러리 (주)Lark 문서)

사용 예제:

import os
import re
from openai import OpenAI

base_url = os.getenv("OPENAI_BASE_URL", "http://localhost:8000/v1")
api_key = os.getenv("OPENAI_API_KEY", "EMPTY")
client = OpenAI(api_key=api_key, base_url=base_url)


# Grammar for SQL SELECT statements
sql_grammar = """
root ::= select_statement

select_statement ::= "SELECT " column " FROM " table " WHERE " condition

column ::= "username" | "email"

table ::= "users"

condition ::= "id = " number

number ::= "1" | "2" | "3"
"""

response = client.chat.completions.create(
    model=client.models.list().data[0].id,
    messages=[{"role": "user", "content": "Generate an SQL query to show the 'username' from the 'users' table."}],
    extra_body={
        "structured_outputs": {"grammar": sql_grammar},
    },
    temperature=0.0,
    max_tokens=100
)

content = response.choices[0].message.content
assert content and re.fullmatch(r"SELECT (username|email) FROM users WHERE id = [123]", content.strip()), content
print(content)

위의 예는 EBNF 형식을 사용합니다. ::= 표기. 문법 복잡성 요건에 따라 다른 문법 형식을 사용할 수도 있습니다.

사용 사례:

  • SQL 쿼리 생성

  • 특정 구문을 가진 부호 발생

  • 수학적 표현식

  • 사용자 지정 domain-specific 언어

  • 복잡한 구조 형식

구 버전에서 마이그레이션 guided_* 필드#

2026.2.0 버전 이후 사용 중단됨: The guided_json, guided_regex, guided_choice, 그리고 guided_grammar API 필드는 deprecated이며 향후 릴리스에서 제거됩니다. 사용 structured_outputs 대신 매개 변수.

만약 [deprecated] 버전을 사용 중이라면 guided_* API 필드는 코드를 업데이트하여 새로운 코드를 업데이트하십시오. structured_outputs 매개 변수. deprecated 필드는 계속 작동하지만 deprecation 경고를 방출합니다.

현장 지도#

부진 된 현장

새로운 매개 변수

guided_json

structured_outputs={"json": ...}

guided_regex

structured_outputs={"regex": ...}

guided_choice

structured_outputs={"choice": ...}

guided_grammar

structured_outputs={"grammar": ...}

response = client.chat.completions.create(

response = client.chat.completions.create(
