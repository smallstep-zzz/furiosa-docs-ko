Furiosa-LLM를 사용한 빠른 시작#

Furiosa-LLM는 LLM 모델을 위한 FuriosaAI를 사용하는 서비스 프레임워크입니다. vLLM와 호환되는 Python 및 OpenAI의 API와 호환되는 서버를 제공합니다. 이 문서는 Furiosa-LLM를 설치하고 사용하는 방법을 설명합니다.

경고

이 문서는 Furiosa SDK 2026.4.1에 근거를 둡니다. 여기에서 설명된 특징 및 APIs는 미래에 변화하는 주제입니다.

Furiosa-LLM 설치#

Furiosa-LLM의 최소 요구 사항은 다음과 같습니다.

  • 설치되는 예비 부품이있는 시스템 (see) 사전 설치)

  • Python 3.10, 3.11, 3.12, 3.13 또는 3.14

  • PyTorch 2.5.1

  • 모델 중량에 따라 모델 무게에 대한 충분한 저장 공간 (모델 크기에 따라 다름)

Furiosa-LLM를 설치하려면 다음 명령을 실행하십시오.

pip install --upgrade pip setuptools wheel uv
uv pip install --upgrade --torch-backend=auto furiosa-llm

(선택) Hugging Face 허브 승인#

meta-llama/Llama-3.1-8B와 같은 일부 모델은 실행할 라이센스가 필요합니다. 이를 위해 Hugging Face 계정을 만들 필요가 있으며 모델의 라이센스를 받아 token를 생성합니다. token를 만들 수 있습니다. https://huggingface.co/settings/tokens. 일단 token를 얻을 경우, 당신은 Hugging Face 허브에 다음과 같이 인증할 수 있습니다:

pip install --upgrade huggingface_hub
hf auth login --token $HF_TOKEN

Furiosa-LLM와 오프라인 배치 Inference#

이제 Furiosa-LLM의 Python 및 API를 사용하여 LLM 및 inference를 오프라인으로 사용하는 방법을 설명합니다. 먼저, 다음을 가져옵니다. LLM and SamplingParams furiosa_llm 모듈에서 클래스. LLM 클래스는 LLM 모델을로드하고 LLM inference에 대한 코어 API를 제공합니다. SamplingParams 텍스트 생성에 대한 다양한 매개 변수를 지정하는 데 사용됩니다.

from furiosa_llm import LLM, SamplingParams

# Load the model from Hugging Face model hub
with LLM("furiosa-ai/Meta-Llama-3.1-8B-Instruct-FP8-dynamic") as llm:
    # You can specify various parameters for text generation
    sampling_params = SamplingParams(min_tokens=10, top_p=0.3, top_k=100)

    # Prompt for the model
    message = [{"role": "user", "content": "What is the capital of France?"}]
    prompt = llm.tokenizer.apply_chat_template(message, tokenize=False)

    # Generate text
    response = llm.generate([prompt], sampling_params)

    # Print the output of the model
    print(response[0].outputs[0].text)

Furiosa-LLM와 Inference 스트리밍#

inference, Furiosa-LLM를 배치하는 이외에, 또한 스트리밍 inference를 지원합니다. 스트리밍 inference의 핵심 차이점은 토큰이 생성되는 즉시 반환됩니다. 이것은 전체적인 inference 프로세스 완료 전에 부분 토큰을 인쇄 또는 처리하기 시작할 수 있습니다. 스트리밍 inference를 수행하려면, 사용 stream_generate 방법 대신 generate. 이 방법은 비동기이며 생성 된 토큰의 스트림을 반환합니다.

import asyncio
from furiosa_llm import LLM, SamplingParams


async def main():
    # Load the model from Hugging Face model hub
    with LLM("furiosa-ai/Meta-Llama-3.1-8B-Instruct-FP8-dynamic") as llm:
        # You can specify various parameters for text generation
        sampling_params = SamplingParams(min_tokens=10, top_p=0.3, top_k=100)

        # Prompt for the model
        message = [{"role": "user", "content": "What is the capital of France?"}]
        prompt = llm.tokenizer.apply_chat_template(message, tokenize=False)

        # Generate text and print each token at a time
        async for output_txt in llm.stream_generate(prompt, sampling_params):
            print(output_txt, end="", flush=True)


# Run the async main function
if __name__ == "__main__":
    asyncio.run(main())

Inference와 Furiosa-LLM 간의 채팅#

OpenAI-Compatible Server 출시#

Furiosa-LLM는 OpenAI와 호환되는 API를 제공하는 서버로 배포될 수 있습니다. 많은 LLM 프레임 워크와 응용 프로그램이 OpenAI의 API의 상단에 내장되어 있기 때문에 기존 애플리케이션에 Furiosa-LLM를 쉽게 통합할 수 있습니다.

기본적으로 서버는 HTTP 엔드포인트를 듣습니다. http://localhost:8000. 바인딩 주소와 포트를 지정하여 변경할 수 있습니다. --host and --port 옵션. 서버는 이제 한 번에 하나의 모델을 호스팅 할 수 있으며 채팅 템플릿 기능을 제공합니다. 더 많은 세부 정보를 찾을 수 있습니다. OpenAI 호환 서버 부문

아래는 Llama 3.1 8B Instruct 모델로 서버를 실행하는 방법의 예입니다.

# Launch the server to listen on port 8000 by default
furiosa-llm serve furiosa-ai/Llama-3.1-8B-Instruct

서버는 모델을로드하고 지정된 포트에 청취를 시작합니다. 서버가 준비되면 다음 메시지를 볼 수 있습니다.

INFO:     Started server process [27507]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)

그런 다음 다음 curl 명령을 사용하여 서버를 테스트 할 수 있습니다.

curl http://localhost:8000/v1/chat/completions \
    -H "Content-Type: application/json" \
    -d '{
    "model": "EMPTY",
    "messages": [{"role": "user", "content": "What is the capital of France?"}]
    }' \
    | python -m json.tool
