Furiosa-LLM을 사용한 빠른 시작#

Furiosa-LLM은 FuriosaAI의 NPU를 사용하여 LLM 모델을 제공하는 서비스 프레임워크입니다. vLLM과 호환되는 Python API와 OpenAI API와 호환되는 서버를 제공합니다. 이 문서는 Furiosa-LLM 설치 및 사용 방법을 설명합니다.

경고

본 문서는 Furiosa SDK 2026.4.1을 기반으로 작성되었습니다. 본 문서에 설명된 기능 및 API는 향후 변경될 수 있습니다. (Furiosa SDK 2026.4.1)

Furiosa-LLM 설치#

Furiosa-LLM의 최소 요구 사항은 다음과 같습니다:

  • 설치되는 예비 부품이있는 시스템 (see) 사전 설치)

  • Python 3.10, 3.11, 3.12, 3.13 또는 3.14

  • PyTorch 2.5.1

  • 모델 가중치에 충분한 저장 공간 (모델 크기에 따라 다름)

Furiosa-LLM을 설치하려면 다음 명령을 실행하십시오:

pip install --upgrade pip setuptools wheel uv
uv pip install --upgrade --torch-backend=auto furiosa-llm

Hugging Face Hub 인증 (선택 사항)#

일부 모델, 예를 들어 meta-llama/Llama-3.1-8B은 실행에 라이선스가 필요합니다. 이러한 모델의 경우, Hugging Face 계정을 생성하고 모델의 라이선스를 수락하고 토큰을 생성해야 합니다. 토큰은 다음 URL에서 생성할 수 있습니다: https://huggingface.co/settings/tokens. 토큰을 얻은 후, Hugging Face Hub에서 인증할 수 있습니다:

pip install --upgrade huggingface_hub
hf auth login --token $HF_TOKEN

Furiosa-LLM을 사용한 오프라인 배치 추론#

이제 Python API를 사용하여 Furiosa-LLM을 사용하여 오프라인 LLM 추론을 수행하는 방법을 설명합니다. 먼저, furiosa_llm 모듈에서 LLM 및 SamplingParams 클래스를 가져옵니다. LLM 클래스는 LLM 모델을 로드하는 데 사용되며, LLM 추론의 핵심 API를 제공합니다. SamplingParams는 텍스트 생성에 대한 다양한 매개변수를 지정하는 데 사용됩니다.

from furiosa_llm import LLM, SamplingParams

# Load the model from Hugging Face model hub
with LLM("furiosa-ai/Meta-Llama-3.1-8B-Instruct-FP8-dynamic") as llm:
    # You can specify various parameters for text generation
    sampling_params = SamplingParams(min_tokens=10, top_p=0.3, top_k=100)

    # Prompt for the model
    message = [{"role": "user", "content": "What is the capital of France?"}]
    prompt = llm.tokenizer.apply_chat_template(message, tokenize=False)

    # Generate text
    response = llm.generate([prompt], sampling_params)

    # Print the output of the model
    print(response[0].outputs[0].text)

Furiosa-LLM을 사용한 스트리밍 추론#

배치 추론 외에도, Furiosa-LLM은 스트리밍 추론도 지원합니다. 스트리밍 추론의 주요 차이점은 토큰이 생성되는 즉시 반환된다는 것입니다. 이를 통해 전체 추론 프로세스가 완료되기 전에 부분 토큰을 출력하거나 처리할 수 있습니다. 스트리밍 추론을 수행하려면 stream_generate 메서드를 generate 메서드 대신 사용합니다. 이 메서드는 비동기적으로 실행되며, 생성되는 토큰의 스트림을 반환합니다.

import asyncio
from furiosa_llm import LLM, SamplingParams


async def main():
    # Load the model from Hugging Face model hub
    with LLM("furiosa-ai/Meta-Llama-3.1-8B-Instruct-FP8-dynamic") as llm:
        # You can specify various parameters for text generation
        sampling_params = SamplingParams(min_tokens=10, top_p=0.3, top_k=100)

        # Prompt for the model
        message = [{"role": "user", "content": "What is the capital of France?"}]
        prompt = llm.tokenizer.apply_chat_template(message, tokenize=False)

        # Generate text and print each token at a time
        async for output_txt in llm.stream_generate(prompt, sampling_params):
            print(output_txt, end="", flush=True)


# Run the async main function
if __name__ == "__main__":
    asyncio.run(main())

Furiosa-LLM을 사용한 챗 추론#

Furiosa-LLM는 high-level를 제공합니다. chat 채팅 기능을 갖춘 모델에 대한 방법. 이 방법은 내부적으로 prompt를 처리하여 상호 작용을 단순화합니다 - 그것은 적절한 채팅 템플릿을 적용하고 호출합니다. generate 방법을 사용하여 prompt 형식의 데이터를 처리합니다.

챗 API 사용에 대한 자세한 예시는 다음을 참조하십시오:

  • 채팅

  • 도구 호출 (Tool Calling)

OpenAI 호환 서버 시작#

Furiosa-LLM은 OpenAI와 호환되는 API를 제공하는 서버로 배포될 수 있습니다. 많은 LLM 프레임워크 및 애플리케이션이 OpenAI API를 기반으로 구축되어 있으므로, Furiosa-LLM을 기존 애플리케이션에 쉽게 통합할 수 있습니다.

기본적으로 서버는 http://localhost:8000에서 작동합니다. --host 및 --port 옵션을 사용하여 바인딩 주소와 포트를 변경할 수 있습니다. 현재 서버는 한 번에 하나의 모델만 호스팅할 수 있으며, 챗 템플릿 기능을 제공합니다. 자세한 내용은 OpenAI 호환 서버 섹션에서 확인할 수 있습니다.

다음은 Llama 3.1 8B Instruct 모델을 사용하여 서버를 시작하는 예시입니다.

# Launch the server to listen on port 8000 by default
furiosa-llm serve furiosa-ai/Llama-3.1-8B-Instruct

서버는 모델을 로드하고 지정된 포트에서 수신을 시작합니다. 서버가 준비되면 다음과 같은 메시지를 보게 됩니다:

INFO:     Started server process [27507]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)

그런 다음, 다음 curl 명령을 사용하여 서버를 테스트할 수 있습니다:

curl http://localhost:8000/v1/chat/completions \
    -H "Content-Type: application/json" \
    -d '{
    "model": "EMPTY",
    "messages": [{"role": "user", "content": "What is the capital of France?"}]
    }' \
    | python -m json.tool
