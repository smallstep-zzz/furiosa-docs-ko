FuriosaAI 소프트웨어 업그레이드#

참고

Furiosa SDK 2026.4는 다음을 필요로 합니다. 2026.4.0 RNGD driver- 업그레이드 furiosa-driver-rngd Furiosa-LLM 2026.4를 실행하기 전에. 2026.3.x driver를 사용하여 예상치 못한 문제를 일으킬 수 있습니다. 또한 CLI 및 Python 구성 마이그레이션 테이블을 검토합니다. 🚨 주요 변경 사항 및 폐기.

high-level 업그레이드 워크플로우는 다음과 같습니다:

  1. driver 패키지 업그레이드.

  2. firmware 도구 및 이미지를 새 버전이 사용할 수 있는지 업그레이드하십시오.

  3. 장치 firmware가 업그레이드된 경우 시스템의 냉 재부팅을 수행하십시오.

  4. 실행 furiosa-smi info CLI 도구는 모든 장치에서 새로운 driver 및 firmware 버전을 확인합니다.

  5. 필요한 경우 Furiosa-LLM를 업그레이드하십시오.

경고

SDK를 업그레이드하기 전에 NPU를 사용하여 모든 실행 응용 프로그램을 중지해야합니다. 그렇지 않으면 새로운 driver 커널 모듈이로드되지 않습니다. 그 경우 새로운 driver 커널 모듈을로드하기 위해 시스템을 재부팅해야합니다.

Driver, Firmware 및 furiosa-smi 업그레이드#

Furiosa 소프트웨어 스택을 업그레이드하려면 아래 단계를 따르십시오.

sudo apt update && sudo apt install -y furiosa-driver-rngd furiosa-smi

sudo dnf makecache && sudo dnf upgrade -y furiosa-driver-rngd furiosa-smi

sudo dnf makecache && sudo dnf upgrade -y furiosa-driver-rngd furiosa-smi

Furiosa SDK의 주요 출시는 firmware 업그레이드를 포함합니다. firmware 업그레이드 전에 firmware 업데이트기와 firmware 이미지 패키지를 설치하십시오:

sudo apt install -y furiosa-firmware-tools-rngd furiosa-firmware-image-rngd

sudo dnf install -y furiosa-firmware-tools-rngd furiosa-firmware-image-rngd

sudo dnf install -y furiosa-firmware-tools-rngd furiosa-firmware-image-rngd

모든 RNGD 장치에서 firmware를 업그레이드하려면 다음을 실행하십시오.

sudo furiosa_rngd_updater_all

대안으로, 당신은 BDF와 firmware 이미지를 지정하여 특정 RNGD에 firmware를 업그레이드 할 수 있습니다 :

sudo furiosa_rngd_updater -b <BDF> -f <firmware image>
# Example:
# sudo furiosa_rngd_updater -b 0000:43:00.0 -f /usr/lib/firmware/furiosa-rngd/rngd_fw_v2026.3.0.bin

참고

2026.3 릴리스 전에 firmware 업데이트자는 firmware 이미지 패키지가 설치되었을 때 자동으로 실행되었습니다. 2026.3 릴리스로 시작하면 firmware 업데이트기를 수동으로 실행해야합니다.

참고

firmware 업그레이드 프로세스가 완료된 후 시스템을 재부팅하는 것을 기억하십시오. firmware 업그레이드 프로세스가 중단되면 장치가 무효화 될 수 있습니다. 이 경우 지원에 FuriosaAI 지원에 문의하십시오.

Furiosa SMI Python 패키지 마이그레이션#

갱신 시 Furiosa SDK 2026.3.0 또는 2026.4.0 이전, 당신의 Python 신청 용도가 사용하는 경우에 이 가이드를 따르십시오 furiosa-smi-py 을 furiosa-smi.

대체 furiosa-smi-py 과 furiosa-smi 애플리케이션의 Python 의존성에서 새로운 패키지를 설치하십시오.

pip install furiosa-smi

패키지는 별도의 수입 이름을 가지고 있으므로 설치 furiosa-smi 기존 데이터를 업데이트하지 않습니다. furiosa_smi_py imports. imports 및 API 호출을 다음과 같이 업데이트하십시오:

Python API 변경#

이전 API (furiosa_smi_py)

새로운 API (furiosa_smi)

import furiosa_smi_py

import furiosa_smi

furiosa_smi_py.init()

호출을 제거; 명시된 초기화는 더 이상 필요하지 않습니다.

device.device_info().name()

device.device_name() 다음과 같은 이름을 반환합니다 npu0.

device.device_info().uuid()

device.uuid()

device.device_info().firmware_version()

device.firmware_version()

device.device_info().serial()

device.serial()

device.device_info().numa_node()

device.numa_node()

device.core_status().pe_status()

device.core_status().items() 생산량 (core, status) 쌍으로

다음 예제는 이전 이후 동일한 장치 정보 및 목록 사용 가능한 코어를 쿼리합니다.

이전: furiosa-smi-py

import furiosa_smi_py as smi

smi.init()
print("Driver:", smi.driver_info())
for device in smi.list_devices():
    info = device.device_info()
    print(info.name().split("/")[-1], info.uuid(), info.firmware_version())
    for pe_status in device.core_status().pe_status():
        if pe_status.status() == smi.CoreStatus.Available:
            print("Available core:", pe_status.core())

다음으로: furiosa-smi

import furiosa_smi as smi

print("Driver:", smi.driver_info())
for device in smi.list_devices():
    print(device.device_name(), device.uuid(), device.firmware_version())
    for core, status in device.core_status().items():
        if status == smi.CoreStatus.Available:
            print("Available core:", core)

core_status() 이제 사전 매핑 코어 인덱스를 반환 CoreStatus 값과 ==, 위와 같이 is Python 객체 정체성을 비교하고 여기에 사용되지 않아야합니다.
